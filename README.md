# Sky Blog 3

Sky Blog 3 是面向 Halo 的 macOS 桌面风格博客主题。把文章、生活记录和兴趣收藏放进一张桌面：通过 Dock 打开内容，在窗口中浏览，再回到桌面。

- 当前正式版本：[v0.9.47](https://github.com/sky121666/theme-sky-blog-3/releases/tag/v0.9.47)，要求 Halo `>=2.26.0`
- 获取主题：[GitHub Releases](https://github.com/sky121666/theme-sky-blog-3/releases) · [Halo 应用市场](https://www.halo.run/store/apps/app-gqnoxtpt)
- 使用指南：[文档索引](docs/文档索引.md) · [完整功能截图](docs/功能展示.md)

## 安装与配置

1. 使用 Halo `>=2.26.0`，下载主题 ZIP，在后台「外观 → 主题」上传并启用。
2. 按 [后台配置指南](docs/设置/后台设置协助说明.md) 设置菜单、桌面入口和插件页面。
3. 登录具有主题配置权限的账号，从 Dock 或菜单栏打开「系统设置」，查看草稿效果后应用。素材选择与布局编辑见上方指南。

升级前备份主题配置和上一稳定 ZIP，完整步骤见 [发布与回滚](docs/发布与回滚.md)。

瞬间、图库、友链与朋友圈、追番、豆瓣、Steam、装备和 Docsme 等内容需要对应插件；搜索、评论和代码高亮也由相应插件提供。安装与更新前请查看 [插件适配状态](docs/插件适配状态.md) 与 [插件契约](docs/插件适配契约.md)。

## 开发

Node `>=24.21.0 <25`，固定使用 pnpm `12.5.1`：

```bash
pnpm install --frozen-lockfile
pnpm run lint
pnpm run typecheck
pnpm run check
```

`check` 包含构建并改写 `templates/assets/**`；运行时变更需同步对应构建资源。其他命令、Halo 重载与浏览器验证要求见 [开发约束](docs/开发约束.md) 和 [验证矩阵](docs/验证与审计矩阵.md)。截图展示与真实配置保存、认证提交、真机验收分别记录。
