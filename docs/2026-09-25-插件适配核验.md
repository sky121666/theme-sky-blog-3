## 变更依据与验证范围

- [PluginLinks 2.3.0 Theme API](https://github.com/halo-sigs/plugin-links/blob/v2.3.0/dev/theme-api.md)：明确 `linkApplicationEnabled`、原生表单/公共 REST、验证码挑战和 `201` 审核申请；主题采用匿名 REST，保留管理员 Link CRUD 和关闭申请时的留言流程。
- [Douban 1.2.6 发布记录](https://www.halo.run/store/apps/app-srBOL/releases)：公共响应改为扁平字段，本机只读 API 返回 `id/name/poster/genres/favesStatus/favesScore/favesCreateTime/favesRemark`，据此更新页面和小组件。
- 其余版本逐项核对上表官方发布记录、主题源码中的路由/Finder/API/字段/模板/样式/脚本与生命周期。发布说明的后台、许可、编辑器或存储变化没有对应主题调用时，只记录“不改码”的理由；不能把这一结论等同于新版本真页已测试。
- 本轮静态与隔离检查：`pnpm --config.verifyDepsBeforeRun=warn run check`、`pnpm --config.verifyDepsBeforeRun=warn run audit:plugins:strict`、`pnpm --config.verifyDepsBeforeRun=warn run verify:shiki-adaptation`、`node scripts/verify-links-adaptation.mjs`、`node scripts/verify-douban-adaptation.mjs`。Shiki fixture 使用本机 1.5.1 资源。`warn` 仅允许现有 pnpm 10 store 在 pnpm 11 CLI 下运行，未安装或升级依赖。
- 真页门禁：按项目 `AGENTS.md` 执行 `verify:reload`，theme3 reload 接口成功返回，但首页仍由 theme2 渲染，30 秒后以 `重载后首页未恢复: 首页状态 200` 退出；因此没有任何 theme3 路由通过记录。`smoke:playwright` 未对 theme2 运行，需在当前主题实际启用且版本组合保持一致后执行。没有执行访客真实申请、评论提交、支付、投票、模型调用或数据迁移。

## 分类结论

- **已验证**：本机 45 插件安装状态、24 项严格版本 fixture、当前代码构建/静态/离线契约、Shiki 1.5.1 隔离浏览器 fixture。
- **待运行验证**：24 个主题插件在 Halo 2.26.1 + 当前 theme3 代码上的实际页面组合；尤其 `/links` 访客申请、`/douban` 列表与小组件、Docsme 高级状态、评论组件、PJAX 注入资源。
- **不适用**：上述 21 个已安装非主题契约插件、退役的 `plugin-friends` 与 `link-submit`、明确不适配的 `plugin-forum`。
- **受阻**：当前本机未启用 theme3，且用户本轮未授权实际站点切换/升级；`plugin-forum` 的官方版本身份无法可靠确认。当前代码不能标记为“最新插件组合运行兼容”。
