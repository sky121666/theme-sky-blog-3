## 审计与改造

| 功能与组件 | 观察到的问题 | 本轮处理 |
| --- | --- | --- |
| 全局搜索 | 官方插件采用两层 Shadow DOM，原表单样式未覆盖内层；外层宽泛选择器误影响滚动容器；Tab 可跳到背景插件 | 分层注入，限制重试期限，统一输入、结果、键帽和面板；选中项使用主题对比色，局部 Tab 循环；支持减少动态效果 |
| 桌面窗口与 Dock 恢复 | 最小化跨异步边界未检查失效状态；动画中恢复点击可能被吞掉 | 取消过期 Genie 动画，核对窗口状态，保留快速恢复请求并清理动画副本 |
| 顶栏菜单 | 悬停打开后点击会反向关闭；方向键与返回焦点不完整 | 统一鼠标与键盘状态，补方向键、Home/End、字符定位、Escape 与菜单互斥 |
| 通知、搜索与分享 | 关闭动画结束可能抢回搜索焦点；分享切换视图焦点不连续 | 按当前焦点归属决定返回；取消过期焦点任务，补面板语义、可见焦点和完成提示 |
| 阅读器 | 窄窗隐藏目录后仍留空列；底部拖柄触摸区域过小；浮动表单按钮遮挡目录 | 切换单列，细柄外观不变、交互区域扩大为 64×44px；目录打开、选择、关闭和回焦成链；展开时暂时隐藏浮动表单，关闭后恢复并保留草稿 |
| Docsme | 缩小应用窗口不等同于缩小浏览器；关闭目录可能仍可键盘进入；正文透出桌面 | 按容器宽度切换目录，补抽屉焦点与 inert 生命周期；正文采用既有不透明内容 token，导航保留玻璃 |
| 图库详情 | 信息和评论面板键盘入口、关闭与回焦不一致；评论编辑器方向键可能触发翻图 | 统一面板状态和 Escape 行为，检查事件穿过的 Shadow DOM 路径，避免编辑时翻图 |
| 商城规格 | 规格选择与图片预览混用点击区域 | 分成两个原生按钮，独立 pressed/expanded 状态、焦点和预览关闭 |
| 商城地址 | 地区加载失败缺少明确状态与就地重试 | 分层加载、前置禁用、错误重试；切换上级清理下级，保留表单其余输入 |
| 购物车 | 初始请求和删除失败缺少稳定恢复；连续点击存在误操作空间 | 加载/删除状态可见、防重复删除，恢复期间限制结算；不自动重放 DELETE |
| Finder、归档、瞬间、友链、图库列表、商城探索 | 已有相对完整的窗口结构与应用布局 | 复用共享壳层改进，保留现有内容组织，不额外叠加悬浮、弹跳和装饰动效 |

## 资源与维护成本

不增加 React、Motion、GSAP 或其他运行依赖。保留既有 **145 KiB Shell JS / 64 KiB Shell CSS** 门禁。

按最终静态依赖闭包逐文件 gzip 统计，Shell JS 为 **148,360 bytes**，相对 HEAD 的 **147,852 bytes** 增加 **508 bytes（约 0.34%）**；Shell CSS 为 **65,494 bytes**，比 HEAD 增加 **68 bytes**。测量不等于网络实际传输量或 Web Vitals。构建中间值早于后置 preload 映射和 URL 处理，最终预算以实际文件为准，见 `budget.json` 与 `baseline-budget.json`。

搜索运行模块改为用户触发后才加载，第一次搜索增加一次小模块请求；首屏不预取。保留同步可用性返回、合并连击，加载期间 Escape／导航离开可取消；失败记录警告并回退官方搜索，下一次允许重试。取消／失败行为有模拟测试；最终实站确认首屏未请求该模块、搜索时才请求。未模拟真实部署网络断线恢复，不把受控 Promise 测试当作该场景已验收。

## 图库转场与操作效率追加修复

用户在 `/photos/photo-8os50ylm?group=photo-group-8ruj7awi` 的截图中发现窗口外的大幅半透明照片和文件名。实站复现确认发生在相册列表进入详情的原生 View Transition 中，并非缩略图悬停。快照位于页面顶层，旧竖卡按新图宽度放大后绕过窗口的裁剪。

本批只修改图库样式、图库控件及 PJAX 的照片预加载函数，保留既有技术栈、420ms 进入动画、详情方向动画和业务接口：

- 限制快照为转场组的完整尺寸、等比例显示并裁剪，避免旧照片和文件名绘制到窗口之外。
- 图片预加载继承目标 `sizes/srcset`，与正式显示使用同一候选；取消、超时撤销未完成来源，仍保留 200ms 导航等待上限。
- 方向键只在当前可见图库的浏览区域生效，排除其它菜单、评论输入、隐藏及最小化窗口；忽略长按重复事件，保留松开后的新按键。
- PJAX 会聚焦详情标题，因此标题仍归属浏览区域；Tab 能唤醒窗口内已隐藏的缩略条，不拦截默认焦点移动，窗口外 Tab 不干扰图库。
- 信息和评论并存时，Escape 按当前面板归属关闭并回焦。官方评论编辑器已处理、标记 `defaultPrevented` 的按键继续交由插件处理。

回归过程中发现并修复了标题焦点漏判和 Tab 唤醒遗漏；分别保留失败测试，再验证修复通过。原实站冷图测试的 Image 替身缺少 `removeAttribute()`，同步补齐该原生接口；真实 Image 取消行为由独立 HTTP 场景验证，没有改写生产代码来迁就测试。

最终构建 **`0.9.50 / 363cac546757`**。验收过程中另一个任务升级 8090，按用户要求等待其恢复，没有操作容器；恢复后记录为 **Halo 2.27.2**，重载与最终实站回归均在恢复后的实例执行。
