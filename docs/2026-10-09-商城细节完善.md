## 分类图标与颜色

后台路径为 **主题设置 → 商城 → 分类导航 → 分类图标与颜色**；前台 **系统设置 → 应用 → 商店**提供同一配置。主题字段为 `shop.navigation.category_appearances`，默认 `[]`，每条包含：

| 字段 | 用途与约束 |
| --- | --- |
| `category_id` | 稳定商品分类 ID；使用已有官方分类选择器，不按分类名称匹配 |
| `icon` | `folder`、`sparkles`、`code`、`palette`、`book-open`、`music`、`gamepad-2`、`camera`、`package`、`wrench` 之一；未配置或未知值回退文件夹 |
| `color` | 可选六位十六进制颜色，如 `#2E5FBD`；空值或非法值跟随主题颜色 |

全部分类页优先使用商城分类已有的 `image`，没有有效图片时显示主题图标；图片以完整比例放入 28 px 图标区，加载失败也会回退。侧栏只使用同一套线性图标并跟随主题强调色，单项颜色不改变侧栏和分类图片。失效分类 ID 不创建虚构分类。

这是一项**主题外观配置**，不新增商品分类数据库字段，不代表官方商城支持任意 Metadata 表单。分类图片读取与主题外观覆盖分属不同来源，不能将 `category_appearances` 说成商城官方分类属性。配置结构、模板和资源生命周期有定向验证；本轮尚未在真实站点保存、回读该新增配置。

### 原生分类元数据核验与官方建议

后续只读核验确认，本地 Halo 商城版 `2.26.1` 的商品分类编辑组件只维护 `parentId/name/slug/description/image`，未挂载 `AnnotationsForm`，对应分类更新逻辑未处理 annotations。普通文章分类则使用 `content.halo.run / Category` 和 `metadata.annotations`；这不是商城商品分类的模型标识。

因此，当前仅向主题增加 `AnnotationSetting` 定义不能使商城原生弹窗出现图标／颜色字段。主题继续采用上述按分类 ID 的外观配置。已向付费版官方 Ideas 提交并回读确认[建议商城商品分类支持元数据表单与扩展字段 #221](https://github.com/orgs/lxware-dev/discussions/221)，建议补齐表单、保存及主题读取能力，并兼容已有分类。

官方契约参考：[元数据表单定义](https://docs.halo.run/developer-guide/annotations-form)、[AnnotationsForm](https://docs.halo.run/developer-guide/plugin/api-reference/ui/components/annotations-form)。本项是当前版本只读核验，不新增数据库字段、配置保存或交易验收。
