# 功能展示

这里收录 `v0.9.47` 的 **20 个功能图集**。README 为每个功能展示一张代表图；进入图集后，按「截图 1、2、3…」查看不同界面和操作状态，具体操作及适配范围见对应使用指南。

图集统一放在 `docs/功能/<功能名>/截图.md`，例如 [图库截图](功能/图库/截图.md) 中的 [截图 1](功能/图库/截图.md#截图-1)、[截图 2](功能/图库/截图.md#截图-2)、[截图 3](功能/图库/截图.md#截图-3)。

截图拍摄于 **2026-10-02**：桌面视口为 `1280 × 720` 或 `1135 × 720`，手机布局使用浏览器 `390 × 844` 窄屏预览。窄屏截图不能代表真机验收；截图呈现当时的页面状态，不能替代配置保存、附件上传、内容发布等写入操作的验收。
