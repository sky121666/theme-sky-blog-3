# 后台设置协助说明

## 结论

这份文档给 **主题维护者、后端协助人员、站点管理员** 使用。
目标只有一个：明确后台该配什么、每组配置会影响哪里。

当前主题设置入口主要有两类：

1. 主题设置：[/settings.yaml](../../settings.yaml)
2. 注解设置：[/annotation-setting.yaml](../../annotation-setting.yaml)

登录后可从顶栏或 Dock 的「系统设置」进入同一份主题配置。前端分为外观、墙纸、Dock、菜单栏、导航菜单、小组件、通知中心、首屏加载、应用、高级 **10 个分类**。前端 schema 共 **77 个路径**：76 个普通设置路径由「应用」保存，`default_layout.layout_json` 经默认布局编辑器独立保存。完整操作见 [前端系统设置](./前端系统设置.md)；**5 个图片字段、7 个图标字段**见 [前端图片与图标设置](./前端图片与图标设置.md)。

前端分类是操作分组，与下面的后台字段分组不完全相同。菜单、文章、分类、标签、独立页面和插件数据的新增、编辑、删除，以及内容注解，仍在相应 Halo 后台资源中处理。

## 主题设置分组

| 分组 | 作用 | 典型使用场景 |
| --- | --- | --- |
| `navigation` | Header / Dock 菜单来源 | 统一选择全局菜单投放位置 |
| `header` | 顶栏标题、时间、登录、工具栏图标、二级菜单背景 | 调整顶栏展示和访客交互 |
| `desktop` | 桌面配色、背景、桌面图标来源 | 调整桌面视觉和挂载图标 |
| `widgets` | 小组件开关、移动端隐藏、天气参数 | 开启首页桌面层能力 |
| `dock` | Dock 外观交互参数 | 调整 Dock 图标大小、间距、放大和玻璃效果 |
| `moments` | 瞬间封面、名片、配色和前端发布开关 | 配置瞬间页面展示与发布入口 |
| `douban` | 豆瓣页标题、说明、图标和配色模式 | 调整 `/douban` 书影音归档页面 |
| `links` | links 页面标题 | 调整全部友链默认标题 |
| `steam` | Steam 窗口背景和资料横幅 | 选择背景图片 |
| `equipments` | 装备页标题和描述 | 调整全部装备页面文案 |
| `sidebar` | 通知中心名称和默认展开方式 | 区分登录用户与访客面板 |
| `default_layout` | 已发布默认桌面布局 JSON | 以服务端保存首页桌面默认布局 |
| `developer` | 调试模式 | 输出前端调试日志 |

## 各组设置说明

### 1. 菜单

关键字段：

- `navigation.header.menu_name`
- `navigation.dock.menu_name`

适合谁来配：

- 站点管理员
- 需要决定 Header 和 Dock 分别使用哪个后台菜单的人

注意：

- Halo 后台菜单是一棵通用导航树，主题不会根据投放位置自动改造字段。
- Header 适合结构完整的主导航，支持一级和二级菜单。
- Dock 适合扁平快捷入口菜单，只读取一级菜单项，二级菜单不会展开。
- 如果一个菜单项既有链接又有子菜单，Header 会优先把它当作分组标题。
- 旧版本保存过的 `header.source.menu_name` 和 `dock.source.menu_name` 仍会被模板读取；在后台「菜单」或前端「导航菜单」选择新值后，以 `navigation.*` 为准。
- 前端只选择菜单来源，不在主题设置中新增菜单项、排序或修改链接。资源列表读取权限与主题配置写入权限分别由 Halo 校验。

最常见需求：

- 想换顶栏菜单来源：看 `navigation.header.menu_name`
- 想换 Dock 菜单来源：看 `navigation.dock.menu_name`
- 想让 Dock 更清爽：单独准备一个只含常用入口的后台菜单

详见：

- [/docs/功能/桌面壳层.md](../功能/桌面壳层.md)

### 2. 顶栏

关键字段：

- `header.logo.icon`
- `header.logo.title`
- `header.theme.enable_frontend_setting`
- `header.theme.default_mode`
- `header.actions.search_enabled`
- `header.actions.auth_enabled`
- `header.actions.mobile_menu_enabled`
- `header.time.*`
- `header.auth.login_label`
- `header.icons.*`
- `header.dropdown.light_bg`
- `header.dropdown.dark_bg`

适合谁来配：

- 站点管理员
- 需要配品牌、访客入口和顶栏工具按钮的人

注意：

- 登录入口固定跳转 `/login`
- 搜索关闭后，`Cmd/Ctrl + K` 也会一起禁用
- 图标项留空时走主题内置 SVG
- 菜单来源不在 `header` 组里配置，统一到 `navigation.header.menu_name`

最常见需求：

- 想改品牌名称：看 `header.logo.title`
- 想改左上角图标：看 `header.logo.icon`
- 想改访客默认明暗模式：看 `header.theme.default_mode`
- 想隐藏登录入口：看 `header.actions.auth_enabled`

### 3. 桌面

关键字段：

- `desktop.appearance.*`
- `desktop.background.*`
- `desktop.icons.*`

适合谁来配：

- 需要调整桌面视觉的人
- 需要决定哪些分类、标签、文章、单页挂在桌面的人

注意：

- `desktop.icons.custom_icons` 适合自由挂载
- `categories / tags / posts / single_pages` 适合结构化内容挂载
- 前端「小组件 → 桌面内容」选择这些资源；取消挂载不删除原资源。标题、正文、发布状态在后台对象中修改
- 已有自定义图标名称用于关联桌面位置；前端系统设置保留该名称，显示标题可在桌面编辑器调整
- 应用挂载变更时，已有完整图标定义的默认布局会同步相关图标记录；其他图标位置和小组件仍由桌面编辑器管理

最常见需求：

- 想换整套桌面配色：看 `desktop.appearance.mode/preset`
- 想自定义强调色：看 `desktop.appearance.accent_color`
- 想换桌面背景：看 `desktop.background.*`
- 想把单页挂到桌面：看 `desktop.icons.single_pages`

### 4. 小组件

关键字段：

- `widgets.behavior.enabled`
- `widgets.behavior.hide_on_mobile`
- `widgets.behavior.edit_enabled`
- `widgets.behavior.fallback_cover`

说明：

- 小组件固定在桌面层，不跟随 PJAX 页面切换消失

最常见需求：

- 想彻底关掉小组件：看 `widgets.behavior.enabled`
- 想手机端隐藏：看 `widgets.behavior.hide_on_mobile`
- 想改天气默认城市：看 `widgets.modules.weather.city_name`

详见：

- [/docs/桌面小组件.md](../桌面小组件.md)

### 7. 豆瓣

关键字段：

- `douban.profile.icon`
- `douban.profile.display_name`
- `douban.profile.subtitle`
- `douban.style.color_mode`

适合谁来配：

- 需要调整 `/douban` 页面识别和品牌感的人

注意：

### 8. 友链

关键字段：

- links 页面现在是独立窗口 app
- 这里配置的是“全部友链”默认标题

最常见需求：

### 9. Steam、装备与通知中心

| 后台组 | 字段 | 作用 | 前端入口 |
| --- | --- | --- | --- |
| Steam | `steam.cover.image_url` | 应用窗口背景和资料横幅；留空使用内置背景 | 应用 → Steam |
| 装备 | `equipments.profile.display_name` | 全部装备标题；留空使用插件标题 | 应用 → 装备 |
| 装备 | `equipments.profile.subtitle` | 全部装备描述；留空使用默认描述 | 应用 → 装备 |
| 通知中心 | `sidebar.notification_center.title` | 登录后面板名称 | 通知中心 |
| 通知中心 | `sidebar.notification_center.guest_title` | 未登录面板名称 | 通知中心 |
| 通知中心 | `sidebar.notification_center.default_open` | 首次进入桌面时是否默认展开 | 通知中心 |

瞬间、豆瓣、友链、Steam 和装备的主题字段可在插件未启用时预配置，但不会安装插件或创建对应页面。插件的内容管理与业务设置仍在插件后台处理。通知中心的主题配置也不会改变通知读取、已读或删除权限。

### 10. 首屏加载

后台字段为 `desktop.startup.mode`、`frequency`、`logo_mode`、`logo_url`；前端入口为「系统设置 → 首屏加载」。默认 `direct`（普通显示），选择 `boot` 后才能设置 `tab_once`（每个标签页首次）或 `every_reload`（首次及每次主动刷新），启动标识可选 `apple`、`site`、`custom`。仅 `custom` 使用 `logo_url`，图片无法加载时回退内置标识。前端「演示一次」只使用未保存草稿，不写配置，也不占用正式播放记录；点「应用」后，下一次符合条件的完整访问才按新配置显示。详见 [前端系统设置](./前端系统设置.md#首屏加载)。

启动配置只控制视觉过渡，不管理站点访问、Halo 登录或资源权限。后台直接修改字段也需要经页面重新读取才可观察效果。

### 11. 默认布局

关键字段：

- `default_layout.layout_json`

说明：

- 这不是手工优先维护的字段
- 前端入口为「小组件 → 桌面管理 → 编辑桌面布局 → 打开布局编辑器…」
- 先处理系统设置草稿及桌面已有未保存修改，再在桌面编辑器中编辑并独立保存发布
- 普通系统设置的应用按钮不直接编辑布局 JSON；打开编辑器本身也不会保存布局
- 布局编辑需要允许编辑布局，读取与保存仍受主题配置权限控制
- 手工改时要保证 JSON 结构正确

最常见需求：

- 想全站替换默认桌面布局：看这里
- 想微调首页默认小组件位置：优先用前端编辑器，不建议直接手改 JSON

### 12. 开发者

关键字段：

- `developer.debug_mode`

说明：

- 开启后会在控制台输出 `[pjax]`、`[desktop]`、`[links]`、`[douban]` 等调试日志
- 日志只覆盖关键操作、失败、降级和 API 组件收口，详细规则见 [/docs/调试日志规范.md](../调试日志规范.md)
- 生产环境建议关闭

## 保存与权限边界

后台主题设置与前端「系统设置」使用同一份 Halo 主题配置。前端普通编辑先进入草稿，点击「应用」后保存；服务端渲染内容需要刷新页面读取。拥有读取配置权限不代表拥有写入、附件、菜单或内容资源的全部权限。

上传图片会立即创建 Halo 附件；取消素材选择、放弃主题草稿或清除图片引用都不删除文件。附件删除与存储策略管理仍在 Halo 后台执行。具体步骤统一见 [前端图片与图标设置](./前端图片与图标设置.md)。

默认布局由桌面编辑器独立保存到 `default_layout.layout_json`。菜单和内容的 CRUD、插件数据和对象注解走各自后台资源，不由主题设置承担。

## 注解设置

包括：

详见：

- [/docs/设置/图标与注解设置指南.md](图标与注解设置指南.md)

## 后台协助建议

### 适合后台直接处理的内容

1. Header / Dock 菜单来源
2. 品牌名称和图标
3. 桌面背景与配色
4. Dock 外观和交互参数
5. 瞬间封面图
6. 桌面图标挂载项

### 不建议后台硬改的内容

1. `templates/assets` 下的构建产物
2. feature 目录和模板路径
3. PJAX 行为
4. shell 交互逻辑

这些属于代码层，不属于后台协助配置范围。
