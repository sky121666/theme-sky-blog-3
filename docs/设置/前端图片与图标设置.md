# 前端图片与图标设置

前端「系统设置」提供 **5 个图片字段和 7 个图标字段**。下面说明素材入口与操作；完整分类、权限和保存流程见 [前端系统设置](前端系统设置.md)。

## 图片字段

| 设置项 | 前端入口 | 保存路径 | 可选图片格式 |
| --- | --- | --- | --- |
| 桌面背景图片 | 墙纸 → 你的图片 → 添加图片 | `desktop.background.image_url` | PNG、JPEG、WebP、GIF、SVG |
| 自定义启动图片 | 启动与登录 → 开机启动 → 启动标识：自定义图片 | `desktop.startup.logo_url` | PNG、JPEG、WebP |
| 小组件回退封面 | 小组件 → 默认封面 → 选择图片 | `widgets.behavior.fallback_cover` | PNG、JPEG、WebP |
| 瞬间封面图片 | 应用 → 瞬间 → 封面图片 | `moments.cover.image_url` | PNG、JPEG、WebP |
| Steam 背景图片 | 应用 → Steam → 背景图片 | `steam.cover.image_url` | PNG、JPEG、WebP |

选择器按当前字段限制附件列表和上传格式。服务端继续决定文件大小、文件类型检查和存储策略限制。应用插件尚未启用时可以预先保存图片引用，但不会因此创建对应页面。

## 墙纸与图片选择

墙纸页顶部显示当前预览，并可通过「背景来源」切换内置墙纸、颜色和已选图片。内置墙纸默认显示一行，点击「全部显示（12）」展开，再次点击「收起」折叠；折叠不会改变当前选择。颜色区使用圆形色块，「＋」打开自定义颜色选择器。「你的图片」提供添加和使用已有图片的入口。尚未选择图片时，来源中的「你的图片」不可选。点击「添加图片」只打开素材选择器，不会仅因打开窗口而切换背景；取消选择也不会写入主题配置。

图片选择器提供三个入口：

1. **附件库**：搜索、翻页并选择 Halo 已有图片。
2. **上传图片**：选择已配置的存储策略，再上传适用于当前字段的图片。
3. **图片地址**：填写 HTTP、HTTPS 地址或 `/upload/...` 等站内路径，点击「预览图片」。

选定图片后，点击选择器中的「使用图片」将其放入设置草稿。桌面背景图片会同时成为当前预览墙纸；其他字段显示所选图片预览。最后点击设置窗口中的「应用」保存引用，必要时刷新页面。

切换到内置墙纸或纯色后，原图片引用可以保留；点击「你的图片」中的「使用图片」可再次切回。点击「移除图片」只解除该引用：如果它正作为墙纸使用，背景草稿回到内置墙纸；如果当前使用纯色或内置墙纸，则保留当前背景模式。其他图片字段的移除行为同样需要应用后保存。

## 上传与取消的区别

上传会立即在 Halo 附件库创建文件，文件由所选存储策略保存。选择器中的「使用图片」和设置窗口中的「应用」分别负责确认草稿引用、保存主题引用；上传成功本身不会发布主题配置。

取消选择、取消设置更改、关闭设置或移除图片引用，都不会删除已上传附件。需要删除文件时，前往 Halo 后台附件管理，并使用具备删除权限的账号处理。

上传超时、结果未确认或尚未生成访问地址时，先刷新附件库检查结果，再决定是否重试。中止等待不代表服务端已取消上传。

附件列表、存储策略读取和附件上传各自受 Halo 权限控制。能编辑主题设置不等于能读取或上传附件；没有可用存储策略时，先在 Halo 后台配置。

## 图标字段

| 设置项 | 前端入口 | 保存路径 |
| --- | --- | --- |
| 应用图标 | 菜单栏 → 菜单栏图标 | `header.logo.icon` |
| 手机端菜单按钮 | 菜单栏 → 菜单栏图标 | `header.icons.mobile_menu` |
| 搜索按钮 | 菜单栏 → 菜单栏图标 | `header.icons.search` |
| 登录按钮 | 菜单栏 → 菜单栏图标 | `header.icons.auth` |
| 浅色模式按钮 | 菜单栏 → 菜单栏图标 | `header.icons.theme_light` |
| 深色模式按钮 | 菜单栏 → 菜单栏图标 | `header.icons.theme_dark` |
| 豆瓣书影音图标 | 应用 → 豆瓣 → 页面图标 | `douban.profile.icon` |

设置行直接显示当前图标；没有自定义图标时，显示主题正在使用的默认图标。点击图标按钮，或聚焦后按 Enter/Space，打开选择器；取消后焦点返回原按钮。在选择器中搜索图标，或从「图标集」选择 Lucide、Material Design Icons 等集合。未设置图标时先显示 16 个常用图标；已有图标会立即回显，并定位到原图标集。支持 `home` 等英文词、`mdi:home` 等完整名称，以及首页、导航、搜索、用户、图片、设置等常用中文词。中文词只做有限映射；未覆盖的词可改用英文或完整名称。

图标集目录和图标数据由 Iconify 按需读取，需要网络连接。桌面结果区固定为 10 列 × 5 排，每页最多显示 50 个图标，通过上一页、下一页浏览；切换图标集或搜索会回到第一页，保留当前选择。当前 SVG、常用图标不依赖在线查询；图标集目录暂时不可用时，仍可搜索或确认当前图标。搜索占位为 `Search icons…`。首次加载的骨架仅限结果区；后续加载保留原结果和当前选择，批次完成后一次替换，不触发全局 PJAX。失败时保留原页，可点击重试。手机或矮窗口内仅滚动结果区，分页与确认按钮保持可用；翻页从结果顶部显示。

界面仅显示当前页码，不用当页条数代表总量。Iconify 搜索只返回累计检索窗口内的数量，无法据此得到可靠的全库总数；主题按 `start` 与累计 `limit` 请求每页名称，额外取一个名称判断下一页，仅获取当前 50 项 SVG。搜索最多覆盖官方接口允许的 999 个候选，达到上限时提示细化关键词；按图标集浏览完整目录不受此搜索上限限制。

请求按图标集批量获取，重复查询与翻页复用有上限的会话缓存；快速切换和关闭窗口会取消不再需要的请求。颜色预览直接处理已选 SVG，不重新查询图标服务。保存后访客页面使用配置中的 SVG，不向图标服务发起请求。

可以让图标跟随界面颜色，也可以设置自定义纯色。仅浏览后确认同一图标、未修改选项时，不改写后台已有对象。点击「使用图标」确认草稿，再在设置窗口应用；「使用默认图标」清空覆盖项，也需应用后保存。菜单栏保持统一显示尺寸，应用页面按自身布局呈现。

图标保存保留 Halo Console 的 `{ value, name, width, color }` 格式，后台可继续编辑。图标 SVG 在预览和写入新设置值前按静态元素与属性白名单重建，不保留脚本、事件、外链、动画、滤镜和 CSS 样式。

Dock 菜单项、分类、标签及其他分组图标属于对应资源的注解，不属于这 7 个主题图标字段；编辑位置见 [图标与注解设置指南](图标与注解设置指南.md)。

## 接口依据与验收记录

附件和图标格式的适配依据为 Halo **v2.26.1** 官方源码：

- [AttachmentEndpoint](https://github.com/halo-dev/halo/blob/v2.26.1/application/src/main/java/run/halo/app/core/attachment/endpoint/AttachmentEndpoint.java)
- [SearchRequest](https://github.com/halo-dev/halo/blob/v2.26.1/application/src/main/java/run/halo/app/core/attachment/SearchRequest.java)
- [IconifyPicker](https://github.com/halo-dev/halo/blob/v2.26.1/ui/src/formkit/inputs/iconify/IconifyPicker.vue)
- [Iconify 搜索接口实现](https://github.com/iconify/api/blob/main/src/http/responses/search.ts)（2026-09-29 实网核对累计 `limit` 与 `start` 语义）
- [Iconify 搜索分页](https://iconify.design/docs/api/search.html)与[批量图标数据](https://iconify.design/docs/api/icon-data.html)
- [IconifyValue](https://github.com/halo-dev/halo/blob/v2.26.1/ui/src/formkit/inputs/iconify/types.ts)

本功能调用 Halo 既有附件和主题配置接口，不需要为素材选择单独安装插件。具体构建的验证范围见 [项目进度](../项目进度.md)，不能从某一图片、图标或存储策略的结果推定所有字段均已完成真实写入验收。
