# 图标与注解设置指南

## 结论

当前主题常用的图标配置入口有 5 类：

1. Header 工具栏图标
2. 桌面图标
3. Dock 菜单项图标
4. 内容对象注解图标
5. 商城商品分类的主题外观配置

搞不清楚时，先问自己：

- 这是页面级图标，还是内容对象图标？
- 这是后台设置，还是注解设置？

## 常见需求怎么找

| 我想改什么 | 先看哪里 |
| --- | --- |
| 改 Header 固定按钮图标 | `settings.yaml -> header.icons.*` |
| 改首屏启动标识 | 「系统设置 → 首屏加载」或 `settings.yaml -> desktop.startup.*`；这是启动层图片选择，不是 Iconify 图标字段 |
| 改桌面挂载图标 | `settings.yaml -> desktop.icons.*` |
| 改 Dock 菜单项图标 | `annotation-setting.yaml -> MenuItem` |
| 改 Header 二级菜单前置分隔线 | `annotation-setting.yaml -> MenuItem.header_separator_before` |
| 改标签图标 | `annotation-setting.yaml -> Tag` |
| 改文章分类图标和颜色 | `annotation-setting.yaml -> Category` |
| 改商城商品分类图标和颜色 | 「主题设置 → 商城 → 分类导航 → 分类图标与颜色」或「系统设置 → 应用 → 商店」 |
| 改图库相册图标 | `annotation-setting.yaml -> PhotoGroup` |
| 改图库相册简介（小组件底部说明文字） | `annotation-setting.yaml -> PhotoGroup` |
| 改友链分组图标 | `annotation-setting.yaml -> LinkGroup` |

## 1. Header 工具栏图标

管理员可在「系统设置 → 菜单栏 → 菜单栏图标」选择这 5 个按钮图标；预览与选择只改草稿，点击系统设置「应用」后保存。取消选择不会改已保存图标。主题另有 `header.logo.icon`（应用图标）与 `douban.profile.icon`（书影音图标），合计 7 个普通 Iconify 图标字段，入口和素材限制见 [前端图片与图标设置](前端图片与图标设置.md#图标字段)。商城分类另用结构化外观列表；Dock 菜单项和其他内容对象图标继续在各自资源注解中管理。

配置位置：

- [/settings.yaml](../../settings.yaml)

字段：

- `header.icons.mobile_menu`
- `header.icons.search`
- `header.icons.auth`
- `header.icons.theme_light`
- `header.icons.theme_dark`

规则：

- 留空：使用主题内置图标
- 非空：覆盖对应按钮图标
- 当前使用 `iconify(svg)` 字段类型

适用场景：

- 想统一替换顶部工具栏图标风格

## 2. 桌面图标

配置位置：

- [/settings.yaml](../../settings.yaml)

字段：

- `desktop.icons.custom_icons`
- `desktop.icons.categories`
- `desktop.icons.tags`
- `desktop.icons.posts`
- `desktop.icons.single_pages`

### `custom_icons`

适合：

- 自定义挂载 `/about`
- 挂外链
- 想自己定图标风格

关键字段：

- `name`
- `href`
- `type`
- `external`

`type` 当前支持：

- `folder`
- `document`
- `link`

### 结构化挂载

适合：

- 分类
- 标签
- 多篇文章
- 单页

这几类不需要手写 href，直接从后台选择对象即可。

## 3. Dock 菜单项图标

配置位置：

- [/annotation-setting.yaml](../../annotation-setting.yaml)

作用对象：

- `MenuItem`

支持 3 种来源：

1. `iconify`
2. `custom_svg`
3. `image`

对应字段：

- `icon_type`
- `icon`
- `custom_svg`
- `image_url`
- `bg_color`

建议：

- 默认优先 `iconify`
- 只有需要完全定制时才用 `custom_svg`
- 图片模式适合品牌图标或动态图片
- 图片必须使用 Halo 附件生成的 `/upload/...` URL 或外部 `https://...` URL
- 不支持 `data:image/...;base64,...` 内联图片；主题会显示轻量回退图标，避免每个 HTML 响应重复携带大图

若旧菜单项已经保存为 Base64，请在 Halo 后台重新选择一次附件并保存。迁移后可用浏览器
Network 确认首页 HTML 不再包含 `data:image`，Dock 图片作为独立资源加载并复用缓存。

额外字段：

- `header_separator_before`

作用：

- 只对 Header 的二级菜单项生效
- 会在当前项前面插入一条分隔线

## 4. 标签、分类与相册图标

### 标签

对象：

- `Tag`

字段：

- `icon`（主题注解）
- `spec.color`（Halo 标签自带颜色）

用途：

- 标签 Finder 列表
- 随机标签小组件

### 文章分类

对象：

- `Category`

字段：

- `icon`
- `color`

用途：

- 分类 Finder 列表
- 桌面分类小组件

这是 Halo 文章分类 `Category`（`content.halo.run`），已有 [AnnotationSetting](../../annotation-setting.yaml) 定义，可在文章分类资源的元数据入口填写图标与颜色。它与商城商品分类 `ProductCategory` 是不同资源，配置不会互通。

### 商城商品分类

配置入口为「主题设置 → 商城 → 分类导航 → 分类图标与颜色」，前端为「系统设置 → 应用 → 商店 → 分类图标与颜色」。外观保存在 `shop.navigation.category_appearances`，每条选择一个真实商品分类，用其稳定 ID 关联：

| 字段 | 用途 |
| --- | --- |
| `category_id` | 商品分类 ID；每个分类配置一次 |
| `icon` | 文件夹、灵感、代码、设计、阅读、音乐、游戏、摄影、商品或工具图标 |
| `color` | 可选六位十六进制颜色，如 `#2E5FBD`；仅用于类别内容区图标 |

类别内容区优先显示商城分类自带图片，没有有效图片或图片加载失败时回退图标；未配置外观时使用默认文件夹图标。颜色留空跟随主题强调色，侧栏图标始终跟随主题强调色；颜色不覆盖分类图片。分类图片仍在商城分类后台编辑。

「侧栏精选分类」是独立的 `shop.navigation.sidebar_categories`：可选择父分类、子分类及更深层级分类，并调整保存顺序；外观列表只控制显示样式，不会把分类自动加入侧栏。前端修改先进入草稿，点击「应用」后保存，再刷新页面读取。

已核对的本地 Halo **2.26.1** 商城商品分类使用原生编辑器，完整编辑界面及保存逻辑没有文章分类式的元数据／`AnnotationSetting` 入口。因此当前主题使用上述主题配置，不为 `ProductCategory` 添加未经支持验证的 `targetRef`。这项边界只描述已核对版本，后续版本需重新核验。扩展建议已提交至 [Halo Pro 官方讨论 #221](https://github.com/orgs/lxware-dev/discussions/221)，不代表官方已提供支持。

新增分类外观的真实保存、回读尚未执行；源码与隔离验证范围见 [商城细节完善](../2026-10-09-商城细节完善.md#分类图标与颜色)。

### 相册

对象：

- `PhotoGroup`

字段：

| 字段名 | 类型 | 说明 |
| --- | --- | --- |
| `icon` | iconify（SVG） | 相册图标，显示在侧边栏和图库小组件角标 |
| `description` | 文本 | 相册简介，显示在图库小组件底部说明区（建议 15 字以内） |

配置入口：

Halo 后台 → 图库 → 分组列表 → 编辑分组 → **元数据** 标签页

用途：

- `icon`：图库侧边栏相册图标 + 图库小组件角标 SVG
- `description`：图库小组件底部大字说明（优先于相册名显示）

> **注意**：若 `description` 留空，小组件底部大字回退显示相册 `displayName`。

### 友链分组

对象：

- `LinkGroup`

字段：

- `icon`

用途：

- links 页侧边栏分组图标
- links 页分组标题图标

配置入口：

Halo 后台 → 友链分组 → 编辑分组 → **元数据**

## 5. 选哪种配置链

| 需求 | 配置入口 |
| --- | --- |
| 改 Header 固定按钮图标 | `settings.yaml -> header.icons.*` |
| 改桌面挂载图标 | `settings.yaml -> desktop.icons.*` |
| 改 Dock 菜单项图标 | `annotation-setting.yaml -> MenuItem` |
| 改标签图标 | `annotation-setting.yaml -> Tag` |
| 改文章分类图标和颜色 | `annotation-setting.yaml -> Category` |
| 改商城商品分类图标和颜色 | `settings.yaml -> shop.navigation.category_appearances`，按分类 ID 配置 |
| 改图库相册图标 | `annotation-setting.yaml -> PhotoGroup.icon` |
| 改图库相册简介（小组件底部） | `annotation-setting.yaml -> PhotoGroup.description` |
| 改友链分组图标 | `annotation-setting.yaml -> LinkGroup.icon` |


## 6. 实用建议

1. 全站统一风格时，优先用 `iconify`
2. 想要品牌感时，Dock 单独用 `custom_svg` 或图片
3. 文章分类图标可同时配颜色；商城分类的内容区颜色可留空跟随主题强调色，侧栏保持统一强调色
4. Header 图标留空通常比乱配更稳，因为主题内置图标已经和壳层风格对齐

## 什么时候看这份文档

适合来看这份文档的场景：

1. 后台已经能配图标，但你不知道该配哪一组
2. 想区分 `settings.yaml` 和 `annotation-setting.yaml` 的职责
3. 想统一 Header、Dock、桌面、文章分类、商城商品分类、标签、相册的图标来源
