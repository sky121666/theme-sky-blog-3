# 前端系统设置

登录后，从顶栏或 Dock 的「系统设置」打开主题设置窗口。这里编辑的是当前 Halo 主题的站点配置；应用后影响所有访客。访客自己选择的明暗模式偏好仍然保留。

设置定义来自 [settings.yaml](../../settings.yaml)。前端字段清单对应 [settings-model/schema.js](../../src/shell/desktop-shell/runtime/desktop/settings-model/schema.js)：共 **77 个路径，包含 76 个普通设置路径和 1 个默认布局编辑入口**。路径数量包含分组中的独立字段，不等同于按钮数量。

## 分类与入口

| 分类 | 配置范围 | 路径数量 |
| --- | --- | ---: |
| 外观 | 默认明暗模式、访客切换入口、内置强调色和自定义颜色 | 9 |
| 墙纸 | 背景模式、12 张内置墙纸、纯色、图片 | 4 |
| Dock | Dock 菜单来源、系统设置入口开关、8 项外观参数 | 10 |
| 菜单栏 | 品牌名称与图标、工具按钮、登录文案、时间、二级菜单背景 | 17 |
| 导航菜单 | 菜单栏使用的 Halo 菜单 | 1 |
| 小组件 | 显示与编辑开关、手机端隐藏、回退封面、天气城市与刷新间隔、5 类桌面挂载项、默认布局编辑入口 | 12，其中布局入口 1 项 |
| 通知中心 | 登录后名称、访客名称、进入桌面时是否默认展开 | 3 |
| 首屏加载 | 启动方式、播放频率、启动标识、自定义图片 | 4 |
| 应用 | 瞬间 8 项、豆瓣 4 项、友链 1 项、Steam 1 项、装备 2 项 | 16 |
| 高级 | 调试模式 | 1 |

左侧搜索可以查找分类、字段名称和字段路径。点击搜索结果后进入对应分类或应用详情并定位设置；分类旁的标记表示该分类有尚未应用的修改。应用分类先展示入口列表，点击后进入该应用的详情；顶部返回按钮回到应用列表或上一分类，切换时保留草稿及各页滚动位置。手机端通过顶部分类按钮展开侧栏。

普通开关使用单行标题；只有全站生效、上传保留、布局编辑和权限等需要解释的操作保留说明。外观用浅色、深色、自动预览卡选择；主题配色会一起调整强调色、选中态和文件夹等颜色。墙纸在独立分类中设置；菜单背景提供颜色和不透明度控件，保留已有 HEX/RGBA 取值及透明度。

Dock 分类可以关闭内置「系统设置」入口，顶栏入口仍可使用。入口的名称提示支持悬停和键盘聚焦，关闭放大或减少动态效果时也保持可用；菜单名称和图标继续在 Halo 后台菜单中管理。

## 首屏加载

前端用双缩略预览选择显示方式，选中项显示强调色描边和勾选。开机选项采用分组设置行，「演示一次」位于同组底部。

默认「普通显示」，页面直接出现，内容在原位置补齐。选择「开机启动」后可配置每个标签页首次播放，或首次及每次主动刷新；标识可选苹果、站点标识或自定义图片。站点标识及自定义图片不可用时会显示内置标识。就绪指页面交互初始化完成，远端数据、图片和插件内容可能继续异步加载。启动层在桌面壳层与桌面内容、应用壳层与应用内容或登录页交互就绪后退出；可点击「跳过」或按 Escape 结束，最长等待 2 秒。减少动态效果时直接显示。

修改启动方式只更新草稿，不立即遮盖当前桌面。只有选中「开机启动」才显示「演示一次」；它使用当前草稿，点「结束演示」或按 Escape 可退出，结束后焦点回到原按钮。演示失败会提示且保留草稿；演示不保存配置，也不影响首次播放记录。点「取消」则放弃未应用的启动设置。点击「应用」后，在下一次符合频率条件的完整访问中生效。PJAX、历史恢复、登录后的后续导航与主题自动恢复重载不重复播放。

启动设置不启用或关闭登录保护，也不修改 Halo 的许可证、认证方式或访问权限。

2026-09-30 的[首屏设置验收摘要](../项目进度.md#当前状态)覆盖入口、草稿、演示、取消、模拟配置 GET/PUT 和 375px 布局。配置写入由 fixture 接收，真实 Halo 写入为 0；该记录不证明真实账号权限、持久化、真机触摸或当前匿名站点全站路由验收。本机原始报告位于 `output/first-screen-settings-2026-09-30/browser/report.json`，未包含在新检出仓库中。

## 编辑、应用与刷新

1. 调整需要修改的项目。外观、墙纸、Dock 和部分菜单栏、小组件设置会在当前桌面预览；素材选择器也提供图片或图标预览。菜单来源、桌面内容、应用页面和调试等服务端渲染设置，以应用后的页面刷新为准。
2. 确认预览结果后，点击底部「应用」。这个动作才会把普通设置草稿写入 Halo 主题配置。
3. 保存后使用「刷新页面」，使服务端渲染的标题、菜单、桌面内容和应用页面读取新配置。仍有新草稿时，先处理草稿再刷新。

「取消」会恢复本次尚未应用的主题设置草稿与预览，不会回滚已经保存的设置。关闭窗口时如有未应用修改，会先提醒；再次确认关闭会放弃草稿。

保存前会读取最新主题配置，只合并本次修改的字段。同一字段已在其他位置改变时会提示冲突并保留当前草稿；保存期间继续编辑产生的修改也会留在草稿中。这是保存前的冲突检查，不是服务端原子事务保证；应避免在多个窗口同时编辑同一桌面布局。遇到冲突，先记下需要保留的修改，再重新打开设置读取当前配置。

## 每种操作保存到哪里

| 操作 | 数据与生效位置 | 权限或限制 |
| --- | --- | --- |
| 修改控件、切换分类、搜索、预览 | 当前设置窗口的草稿与本页预览 | 尚未写入主题配置 |
| 「应用」 | 当前主题的 Halo JSON 配置，对应 `settings.yaml` 路径 | 需要主题配置写入权限；服务端决定最终结果 |
| 选择已有图片、填写图片地址、选择或恢复默认图标 | 先写入设置草稿；应用后保存 URL 或图标配置 | 打开素材选择器本身不保存主题；读取附件另需附件权限 |
| 上传图片 | 立即在 Halo 附件库创建文件，由所选存储策略保存 | 需要读取存储策略及上传附件权限；取消草稿不删除文件 |
| 移除图片引用 | 先清空草稿中的对应图片字段，应用后保存 | 不删除附件库中的原文件 |
| 选择菜单来源 | `navigation.header.menu_name`、`navigation.dock.menu_name` | 需要读取菜单的权限；不修改菜单内容 |
| 勾选内容或编辑自定义桌面入口 | `desktop.icons.*`；已有完整图标定义的默认布局还会同步相关图标记录 | 不修改或删除原分类、标签、文章和独立页面 |
| 打开默认布局编辑器并在其中保存 | `default_layout.layout_json` | 使用桌面编辑器独立保存；需要允许编辑布局及对应主题配置权限 |
| 新增、编辑、删除菜单、内容或插件数据 | 相应 Halo 后台资源 | 使用对应后台管理入口及资源权限 |

普通设置和默认布局使用当前主题的配置接口，但保存动作各自独立。文件上传则属于附件操作，不随主题草稿撤销。

## 权限与不可用状态

打开窗口需要登录，并能读取当前主题配置。能够打开窗口，不代表账号具有主题写入、附件上传或内容读取等全部权限；每次接口操作仍由 Halo 校验。

- 菜单、分类、标签、文章和独立页面来自真实 Halo 资源列表。无权限、登录失效或读取失败时会显示提示，可在处理权限或登录状态后重试。
- 桌面内容的「筛选已加载项目」只筛选当前已加载列表；需要其他项目时先使用「加载更多」。不可用内容不能作为新的桌面挂载项，已选项目可取消挂载。
- 应用页显示对应插件是否启用。未启用的应用可以预先保存主题配置，但这些设置不会安装插件、生成页面或创建插件数据。
- 瞬间的前端发布及图片、视频、音频开关只是主题入口设置；实际发布和上传仍遵循瞬间插件、用户账号及附件接口权限。
- 通知中心的名称与展开设置不会授予通知读取、已读或删除权限。

## 桌面内容与默认布局

「小组件 → 桌面内容」可以勾选分类、标签、文章和独立页面，也可以添加自定义名称、链接、图标样式与新窗口开关。取消勾选或移除自定义入口只影响桌面挂载，不删除原内容。

已有自定义图标的名称用于关联桌面位置，因此在系统设置中保持只读；显示标题可在桌面编辑器调整。新图标在保存前可以填写独立名称。内容项目的标题、正文、发布状态，以及菜单项目的排序、链接和图标注解，仍在 Halo 后台编辑。

「小组件 → 桌面管理 → 编辑桌面布局 → 打开布局编辑器…」进入真实桌面的布局编辑。先应用或放弃系统设置草稿；桌面若已有未保存布局，也需要先处理。应用桌面图标增减或属性后，需先刷新页面，再编辑新布局；保存时若发现后台布局已经变化，会拒绝覆盖并保留当前编辑状态。拖动、添加或移除小组件后，在桌面编辑器中点击保存，才会发布默认布局。系统设置中的应用按钮不直接编辑布局 JSON。

当桌面挂载选择与已有完整图标布局一起存在时，应用挂载项会同步对应图标的增减或属性；其余图标位置和小组件布局由桌面编辑器管理。详见 [桌面小组件](../桌面小组件.md)。
