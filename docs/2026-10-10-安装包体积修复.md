# 安装包体积修复

## 原因与实测

对比已下载的正式 GitHub Release ZIP：

| 制品 | 字节数 | 说明 |
| --- | ---: | --- |
| v0.9.47 正式包 | 790,526 | 上一版对照 |
| v0.9.48 正式包 | 7,317,414 | 含三张本地商城 DEMO PNG |
| 本地过滤验证包 | 955,055 | 未发布，仍使用工作区的 0.9.48 标识 |

三张图片压缩后共 6,361,842 bytes，占正式包约 87%、本次增加体积约 97.5%：

- `templates/assets/images/shop-demo/desktop-resources.png`
- `templates/assets/images/shop-demo/icons.png`
- `templates/assets/images/shop-demo/wallpaper.png`

打包器默认递归包含 `templates/**`，因此将本地测试素材带入了安装包。过滤后的包比 v0.9.47 大 164,529 bytes；主要增量为商城代码、样式、模板和设置。

## 修复

- 在现有 `@halo-dev/theme-package-cli@1.1.1` pnpm 补丁中排除 `templates/assets/images/shop-demo/**`，同步补丁锁定 hash。
- `verify-release-package` 明确拒绝该目录及其后代；`finalize-theme-package` 在写入第三方声明后自动执行校验，使常规 `pnpm run package` / `build` 在误带素材时失败。
- 保留开发目录中的三张图片。生产模板和默认设置没有直接引用；商城 fixture 和本地 DEMO 数据继续使用它们。该目录不作为正式安装包的图片来源。

## 初次过滤验证（版本更新前）

- `pnpm run package` 成功，自动制品校验通过，ZIP 为 955,055 bytes。
- 原正式包经新校验及隔离的 finalizer 验证均被拒绝，错误为「ZIP 包含本地演示素材」。
- 实际 `--all` 打包器隔离验证：演示目录被排除，其他图片保留。
- 两个 ZIP 的非目录条目比较：只删除三张 PNG，无新增文件；其余运行代码和模板逐字节相同。两个文本差异为已有 README 正式版本措辞同步、本次 `pnpm-lock.yaml` 补丁 hash 更新。
- `pnpm` 供应链策略检查通过；独立只读审查未发现问题。

上述初次过滤验证没有修改主题模板、版本号、CI/CD 或线上制品，未执行前端重建与 Halo 重载。此诊断包仅用于定位和验证过滤规则，不作为 v0.9.48 的替换发布。
