# 新版插件 PJAX 适配（2026-11-14，工作区）

范围：Halo Pro 2.27.3、CommentWidget 3.5.1、SEO Tools 1.11.1 的主题导航衔接，并逐项核对这次升级的插件。沿用本地 8090，当前活动主题为 theme-sky-blog-1，本项目使用 `preview-theme=theme-sky-blog-3` 验证。未切换活动主题、提交、推送或发布。

## 实现

- **评论分页历史**：识别同一内容中合法的 `comment-page` 变化，保留现有 widget、顶层表单和文档。原生 popstate 仍只到达官方组件一次；仅阻止本次已确认局部遍历进入 Pjax HTML 请求。只包装 3.5.1 已审计的 `syncPageToUrl()` 方法，在官方真实 push 前后标记独立 entry，保留官方方法与主题导航索引；取消时按实际记录的位移返回来源 entry，避免覆盖目标记录后再次 Back／Forward 跳页。其他路径、业务查询、非法或重复分页参数及未知方法继续使用原导航边界，没有全局 History monkeypatch。
- **评论草稿离页**：接入主题既有导航许可，在开放 Shadow DOM 中只读采集官方 base-form 和 comment-edit-form。保护入口在首次导航前固定注册，扫描实现按需加载，避免首次从无评论页进入评论页时因新增保护入口而撤销本次许可。取消、请求失败、导航期间输入均保留原组件与草稿；实际提交／上传／保存中阻止离开。失败后仍保留的提交票据属于待处理草稿，不是永久上传状态。评论分页仅豁免不会被替换的顶层评论表单，回复／编辑仍受保护。已经确认的原生交接只临时去重对应组件自身的 beforeunload，不压制其他插件提醒。
- **评论编辑就绪**：保留 3.4.0 的精确兼容边界，新增实际 3.5.1 仅增加 syncBeforeUnload 的已审方法签名。继续执行官方方法，避免快速输入误成为 baseline，不修改草稿、服务端权限或保存协议。
- **微信／QQ 分享**：识别实际 SEO Tools 1.11.1 的固定脚本封装，只解析其中 JSON 数据，校验字段及 URL，固定使用官方 SDK；不执行响应脚本或生成客户端签名。全量及同 App PJAX 从服务端响应更新；其他局部查询先获取同源目标 HTML，成功提交历史后再配置分享，失败保留源页面。纯 hash 与评论分页不更换文章分享信息。目标签名缺失而 SDK 无法清除旧配置时才使用必要的完整文档交接。适配模块下载失败进入已有导航错误收尾，过期请求不能结束新导航。
- **按需资源**：评论扫描／编辑保护、微信分享和 Shiki 增量桥接从 Shell 的静态加载范围拆出。Shiki 延迟加载后补扫已出现的瞬间，保留最新页面描述符及连接状态检查；初始补扫等待 window.load，避开官方 DCL 渲染，避免双层代码组件。正式资源的预算检查包含写入版本标识后的真实体积，不放宽阈值。
- **版本验证入口**：严格插件清单同步实际安装版本；评论、表单和 Shiki 的专项明确记录所用 JAR／HTTP 制品版本及摘要。SDK 模拟回归进入 `verify:wechat-share`；本机实际插件组合回归入口为 `verify:plugins:current`。
