## 当前方案与实测

读者指向一篇文档时，Swup 可以提前取正文；只有真正点击才由主题 PJAX 检查评论草稿、更新窗口和历史。新正文就绪后，以 Amicro 的缓动曲线淡入并上移 3px，时长 160ms。使用浏览器原生动画，无需引入 React；桌面背景、Dock、小组件不跟着换页。

最多同时猜测两个链接，点击不等其他预取排队。同一篇、同一查询的在途 GET 可以共享；下载完成后，是否还能复用由响应头决定。匿名实站响应的 `max-age=3` 是 3 秒，`s-maxage=120` 不给浏览器 120 秒。声明 `no-store` 的正文不进入主题缓存。失败、离开、返回焦点与草稿规则见[主题导航契约](主题导航契约.md#验证与恢复)。

## 第一轮接入边界（历史）

- 固定 `swup@4.10.0` 与 `@swup/preload-plugin@3.2.12`，版本由注册表及实际安装包核验。
- 第一阶段实际接入 Swup 的文档获取、内存缓存、官方预加载队列和进行中请求去重；不将本轮描述为完整导航引擎替换。
- 标准 Swup 构造函数调用 enable 后会绑定 click/popstate、写入初始 history；本轮使用固定版本的窄子类覆盖 enable/destroy，只经公开 use/unuse 挂载预加载插件，不全局修改 History 或第三方源码。
- 点击准入、请求代次、DOM 提交、Alpine／插件生命周期、历史、滚动和错误恢复仍由现有主题协调器统一负责；文档内 forward GET 消费 Swup 返回的响应。跨应用、浏览器返回、POST 和局部 hash／评论分页保留既有路径。
- 预加载仅限当前文档域、同源合规链接，排除下载、外站、独立窗口及其他应用；完整 URL 区分查询参数和主题预览。缓存短期、有限容量，失败不缓存，失效后禁止旧请求写回。
- 文档内容进入采用可取消的小幅淡入，保留窗口和导航结构；减少动态效果直接展示，失败／取消不播放新页入场。

## 第一轮验收方法

1. 先运行新增回归观察旧代码未预取／未复用的 RED，再接入真实 Swup 与官方插件，不用模拟 Swup 证明自身功能。
2. 隔离网络验证 hover/focus/touch 预取、点击复用进行中的请求、查询分离、失败重试、取消／旧响应、history 唯一性、跨应用、锚点和减少动态效果。
3. 先构建，再运行当前资源身份、相关专项与完整 check；模板／生成资源重载使用主题 3 预览，保留 8090 当前活动主题。
4. 在 8090 同构建真实文档目录与正文完成桌面／手机验证，记录请求次数、是否复用及页面错误；没有实测不宣称性能提升幅度。
5. 独立审查后记录实现、验证及局限。本轮先完成文档试点，不自动扩大到其他应用。

本机证据放在 `output/swup-docs-20261114/`，不进入正式主题包。回退时只撤销本轮文件及接线并重建资源，不恢复整仓、不覆盖已有 WIP。

## 第一轮的验证边界

- 标准全站 `SMOKE_BASE_URL=http://localhost:8090 pnpm run smoke:playwright` 退出 1：活动首页属于主题 1，身份门禁按约定拒绝。`DOCSME_FIXTURE_ONLY=true pnpm run verify:docsme` 也在同一环境身份检查处退出 1。没有切主题、放宽门禁或把它们算成通过。
- 公式样本 `docsme-katex-sample` 的原始服务端 HTML 只有 `$` 文本，没有公式容器；原始内容与 Swup 后一致。流程图样本 `docsme-mermaid-sample` 的原始 HTML 只有 fenced code，没有 `text-diagram`／`.mermaid` 容器。两者的真实渲染验收保留为缺有效样本，未写入数据库修改样本，也未改动富文本协议。原始超时与基线核对保留在 `live-rich-content-*.log/json`。
- 文档中的 Shiki 代码组件另行查看实际挂载和显示；这不等于上述流程图已经渲染。此前预览背景小组件请求漏带 `preview-theme` 的已知问题不属于本批修复。
- 缓存为 20 秒、最多 12 页；离开文档、窗口恢复焦点／pageshow、评论创建即失效。没有跨用户持久缓存，也不对不支持的网络预取强制发起猜测请求。
- 固定版本子类依赖已审计的 Swup 构造生命周期，升级 Swup 时必须重新核验 enable／history／监听所有权；不可直接恢复标准自动初始化。当前仅文档域启用，其他页面尚未扩展。

Vite 告警的上游说明将影响范围限定为 Windows 的编辑器启动路径，并列出 8.3.3 修复版本；本机审计失败状态仍保留。[官方安全公告](https://github.com/advisories/GHSA-587h-7wmj-h5pm)
