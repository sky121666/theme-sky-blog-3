## 第三批：最小修复边界

| 类型 | 允许修复 | 不做 |
| --- | --- | --- |
| 插件资源误加载 | 页面级 gating、延迟加载 | 改插件内部包体 |
| 性能真实异常 | 只修异常页面 | 全局缓存、虚拟列表、复杂预加载 |
| 样式共享风险 | 明确共享样式来源和引用边界 | 为拆分而拆分 |

| 视觉偏差 | Dock、Header、图标、壁纸微调 | 堆强玻璃、重阴影、过度动画 |

## 执行门禁

以下为执行顺序要求：构建当前源码后，再完成类型、契约与离线 fixture、资源预算和构建 smoke。`pnpm run check` 必须保持这一顺序；表中 live 门禁按对应运行环境与授权执行，不能由离线通过推导真页通过。

| 场景 | 命令 / 方法 |
| --- | --- |
| 构建当前资源 | `pnpm run build-only` |
| 静态架构检查 | `pnpm run lint` |
| 类型检查 | `pnpm run typecheck` |

| 构建资源预算 | `pnpm run verify:asset-budget` |
| 构建 smoke | `pnpm run smoke` |
| Halo reload | `pnpm run verify:reload` |

| 全插件兼容门禁 | `SMOKE_BASE_URL=http://localhost:8090 AUDIT_BASE_URL=http://localhost:8090 pnpm run verify:plugins:all` |
| 严格插件 inventory | `pnpm run audit:plugins:strict`（当前完整测试环境精确检查 24 个前台插件；普通部署仍可按需安装） |
