# Swup 动效优化与 8090 验收

本轮在已有全局 Swup 导航上细化动效，不改变 Halo、插件版本和兼容声明，不引入 React、Framer Motion 或新的动效依赖。当前工作区构建为 **`0.9.51 / abefe5f55577`**，在活动主题的 **http://localhost:8090** 验证，未暂存、提交、推送或发布。

## 实现与边界

| 范围 | 本轮行为 |
| --- | --- |
| 加载反馈 | 同应用默认采用轻量进度，保留当前内容；显式窗口骨架策略仍有效。通用遮罩保留 120ms 延迟出现，取消默认 300ms 最短展示，内容就绪后立即开始 120ms 淡出并释放指针命中。ready 仍由原有初始化与清理完成链发出。 |
| 窗口内导航 | 只在当前 accepted 导航成功 ready 后播放局部 160ms 入场；商城列表进入商品详情与返回采用相反方向，历史方向读取真实导航索引。侧边栏背景以 180ms 衔接，失败、过期导航不播放成功入场。 |
| 动效分工 | 文档正文与图库共享图片过渡继续使用原实现，通用正文动效不叠加到这两者。桌面、Dock 与工具栏不参加整页淡出；本轮没有扩大预加载或缓存范围。 |
| 窗口与 Dock | 保留 Genie 和 WAAPI，快速恢复可从正在显示的帧反向接管最小化；同方向连点不重启动画。旧 controller、完成回调和 ghost 不得覆盖新状态。未改 Dock 放大几何。 |
| 商城控件 | 数量修改先进入行内 pending，等实际 PUT 与购物车回读数量一致后才确认；错误可显式再次操作。删除仍等待真实响应和查询恢复。金额区域使用等宽数字与固定对齐，手机数量／删除按钮为 44px。 |
| 图库评论 | 工具按钮补齐按压、禁用、触控与焦点反馈；右侧评论抽屉与侧栏过渡保持一致。保留图片连续切换、原生共享元素过渡和 Escape 焦点恢复。 |
| 通知与小组件 | 首次通知面板保留原入场，重复打开面板为 220ms、背景为 160ms；已稳定内容不重播淡入与错峰。只刷新通知内容，不重新动画外围小组件。现有小组件稳定 key 和局部更新已经满足要求，未增加整卡刷新入场。 |
| 减少动态效果 | 通用入场、高亮、遮罩、窗口、图库控件及购物车反馈均保持减少动态效果路径；新 accepted、pagehide 和销毁负责清理所属动画。 |

Amicro 用作交互参考，不作为运行时安装。核对了上游 `73a6d5c2b28b30ad6f6d98550bb6175cbf51132b` 的 `card-hover`、`scale-in` 等源码，以及技能已审阅版本的受控 toggle；未复制其 React 组件或展示站配色、循环装饰动画。

## 真实页面中发现并修复的细节

首次 8090 观察发现，侧栏原有背景 transition 与新增移动高亮会短暂叠加。现在只在高亮期间暂停该行 transition，结束或取消时先恢复真实选中背景，再恢复原 transition。实站记录确认动画期间原背景透明、transition 为 `none`；结束后临时层和 inline transition 均清理，背景正常恢复。

首次统一构建触发既有壳层 CSS 预算，停止了后续依赖构建资源的检查。清理了导航中已禁用 spinner 对应的未使用样式后重新构建，保持原资源预算，没有放宽门禁。

本轮直接在浏览器操作并查看了以下界面与状态：

- 文档悬停预加载、点击、正文与高亮衔接；Dock 和 document 实例保留。模拟断网时留在原页并清除 busy，恢复网络后再次点击成功；减少动态效果时没有新增正文或高亮动画。证据 `docs-live.json`、`recovery-live.json`。
- 最小化途中立即点击 Dock 恢复，以及多次交替反向操作；新动画从实际 matrix 开始，最终窗口可交互、`isAnimating` 为 false、ghost 为 0。证据 `window-live.json`；减少动态效果下恢复亦无 ghost。
- 通知首次／重复打开、Escape、关闭中重开与多次反向；重复入场实测配置为 220ms／160ms，最后 opacity 为 1。证据 `notification-live.json`。
- 图库网格进入详情、右侧评论、快速开关、Escape 后焦点回到“评论”、下一张；980／768／390px 评论终态均在窗口边界内且页面没有横向溢出，减少动态效果时抽屉与按钮过渡为 0。证据 `photos-live.json`、`photos-responsive-live.json`。
- 商城“商品／类别”、商品详情及浏览器返回，返回入场方向相反，document 实例保留；8090 真实购物车空态无页面错误。证据 `shop-live.json`、`cart-empty-live.json`。购物车非空写入状态由上述 11 项隔离模拟覆盖，没有据此宣称真实订单／支付链路重新验收。

独立只读审查覆盖导航归属与高亮清理、通知旧任务 token、商城回读确认和窗口取消边界。源文件修改前副本、定向日志、截图及汇总保存在 `output/motion-polish-20261115/`，该目录属于本地验收证据，不进入正式安装包。未测量帧率、低端设备性能或量化速度提升。
