| 范围 | 当前实现与边界 |

| 分类行 | 48 px 行高、28 px 图标，仅显示名称；说明保留为原生 `title` 提示 |
| 列布局 | 三列／两列／一列按可用宽度切换；同一 Grid 按列填充、共享行高，子孙展开后下一行跨列继续对齐 |

| 真实设置操作 | 本轮未在后台执行深层分类选取和保存；现有 `[]` 保持不变 |

分类布局不改变商品、分类数据或精选配置。配置可选任意层级的契约与模板递归覆盖，不能代替后台表单实际操作验收。

## 账户入口与官方客户中心

| 状态／入口 | 行为 |
| --- | --- |
| 匿名 | 侧栏底部圆形图标加“登录”；链接携带回到 `/shop/products` 的地址 |
| 已认证 | 通用“我的账户”，使用原生 `details` 展开菜单 |
| 账户中心 | `/uc`，完整文档导航 |
| 我的订单 | `/uc/shop/orders`，完整文档导航 |
| 隐私与请求 | 入口不展示真实账号标识，不额外请求用户资料 |

Halo 官方已提供当前用户资料接口 `GET /apis/uc.api.halo.run/v1alpha1/users/-`，其端点自 **2.26.0** 起提供；本轮入口沿用页面认证状态，不调用该资料接口。[Halo 2.26.1 UcUserEndpoint](https://github.com/halo-dev/halo/blob/v2.26.1/application/src/main/java/run/halo/app/core/endpoint/uc/UcUserEndpoint.java#L49)

当前用户订单接口已在本地固定上游声明 `output/commerce-adaptation-2026-10-08/upstream/halo-dev-api-client-2.24.0/dist/index.d.ts` 的 19025／19046 行登记。现有 shop UI 提供购买、购物车、结算和支付四种组件，没有账户 widget；本轮通过账户入口复用官方 UC，避免另建账户与订单界面。

[官方商城客户中心](https://docs.halo.run/guide/shop/customer-center)承载顾客地址、优惠券与订单；[Halo 2.26.1 登录守卫](https://github.com/halo-dev/halo/blob/v2.26.1/ui/uc-src/router/guards/auth-check.ts#L8)使用 `redirect_uri` 保留返回地址。本轮没有真实登录，也未读取真实订单或执行账户、地址、订单及支付写操作。
