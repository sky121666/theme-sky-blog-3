# 插件界面与交互精修

从 `0.9.51 / dfcf1b4fc65b` 接续。范围为主题承载的前台插件界面、商城和嵌入组件；不重新设计 Halo Console 中的插件后台。保留现有 macOS 外观、系统字体、主题色、桌面/Dock/窗口与公共 Swup；只使用当前 main，保留全部 WIP，不提交、推送、发布、部署，不调整版本或安装依赖。

## 统一方向与动效归属

以完成用户任务为准：真实内容、明确选中、短路径操作、稳定列表、可见焦点、可恢复错误。桌面保持紧凑，手机提高有效点击区域与输入字号；长标题、无图和空态不破坏布局。

共享 Swup 负责预取、HTML 导航、历史、草稿守卫和 accepted/ready/settled。页面等待保留旧内容并即时反馈；组件负责局部筛选、弹窗、列表和媒体状态。不增加页面请求前退场、不叠加整页入场、不按累计卡片数量排队显现。图库保留自己的照片过渡，文档保留正文过渡；减少动态效果仍保留状态确认。

Amicro 的已核对 fade-in registry 依赖 React/framer-motion，仅作为动效归属参照，具体实现沿用现有 CSS/WAAPI；不复制或引入 React 运行时。参考：[固定版本 registry](https://github.com/Subhan-code/Amicro--Micro-transitions-/blob/5a037fc0bfb538bdf3c634a64bdb12022ea13282/registry/ui/fade-in.json)。Halo 模板遵循[当前 Thymeleaf 指南](https://docs.halo.run/developer-guide/theme/thymeleaf.md)，不引入旧 Servlet 表达式对象。

## 验证方式

先看当前构建的真实页面截图并操作，再修改；行为修复补真实回归，纯视觉调整以渲染结果验收。隔离网络/合成内容与 8090 真实内容分别记录，受控写入不冒充真实提交。每个插件记录桌面/390px、页面操作、空/错/加载状态、键盘与减少动态效果。

实现后统一执行完整 check、主题 reload 和 8090 的逐插件操作矩阵，补齐上一轮矩阵未覆盖的图库、豆瓣、追番、Steam、装备与商城。外站 favicon 等原失败独立保留。原始证据位于 `output/plugin-ui-polish-20261116/`。

## 已落地的精修

- 图库：当前图片局部重试、百分比及适合窗口复位、缩放边界、右侧评论独立滚动、窄屏面板定位、信息面板关闭、长相簿名与键盘可读名称。
- 瞬间：评论/回复层次和加载状态、标签/媒体/作者节奏、发布子面板 Escape 顺序、失败保留草稿、通知焦点与取消回焦。
- 友链/朋友圈：搜索清除后保留分组与回焦、手机列表/详情焦点、来源无匹配反馈、助手/留言面板状态。
- 豆瓣：卡片及表格键盘 Quick Look、关闭回焦、按实际列数移动、筛选语义/匹配计数、保留列表的分页失败重试。
- 追番：类型和状态导航当前态、搜索清除/范围计数、手机两行筛选与紧凑图文、手动续载。
- Steam：DOM 与视觉一致的排序、搜索/视图状态、热力图重试和方向键日期读取、分页错误后停止自动重试。
- 装备：逐件前后浏览、当前位置、滚动同步、手动续载、手机图像空间与长分组名称。
- Docsme：项目大厅去掉重复 hero 和层层说明；文档标题改为阅读头；当前面包屑去重；可见项目搜索接入共享 lazy owner；版本/语言切换保留文档后缀、目标权威参数、所有同名 query、preview 和 hash，失败恢复原选择。

Docsme 多语言搜索使用已安装 1.10.2 索引实际采用的 `lang:` 前缀；同包示例的 `language:` 与其 `DocumentConverter` 不一致。8090 同一公开搜索读取验证为旧前缀 0 条、正确前缀 2 条，未改索引和数据库；默认语言读取不能替代全部多语言权限验收。
