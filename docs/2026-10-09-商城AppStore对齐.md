## 首页配置与商品边界

后台主题设置 → **商城 → 首页运营**新增七个字段：

| 字段 | 配置规则 |
| --- | --- |
| `hero_product` | 一个主推商品 ID；为空或失效时隐藏 |
| `hero_image` | 可选宣传横幅；为空时使用完整商品封面 |
| `hero_title` | 可选主推标题；为空时使用商品名称 |
| `hero_description` | 可选主推简介；为空时使用商品简介，沿用全局简介开关 |
| `featured_products` | 最多两个商品 ID，可排序 |
| `compact_products` | 商品行 ID 列表，可排序 |
| `preview_products` | 预览图集 ID 列表，可排序；无有效图片时跳过 |

当前运行包的 `ProductFinder` 提供 `list(Map)`，没有按 ID 取详情的模板接口。模板按真实 ID 在已发布商品分页中查找，未匹配时继续后续页；不按目录位置推荐。失效／下架项跳过。无可展示推荐时，CSS 显示最新商品回退；有有效推荐时隐藏回退及空模块。

售罄判断仅用于 Finder 实际返回非空 `PUBLISHED` SKU 列表，且列表内每个 SKU 都满足 `trackInventory=true`、`stock` 非空且不大于零的情况：主推与双推荐隐藏，商品行保留“暂时缺货”提示。当前 Finder 可能不返回 SKU；缺失 SKU、未知库存、未跟踪库存或部分有货时均不推断售罄。

本地已有六个 DEMO 商品。本轮保存并回读的首页演示配置为：主推 `1`，宣传图 `desktop-resources.png`，标题“给桌面一点新灵感”，双推荐 `2、3`，商品行 `4、6`，预览 `3`。这是有意保留的演示配置，不是恢复到操作前配置。

原始配置备份为本机 `output/appstore-alignment-2026-10-09/config-before.json`，权限 `0600`；完整配置不纳入文档分发。需要恢复时使用该目录的 `configure-demo.mjs restore`。临时失效 ID 与关闭简介验证结束后已重新保存并回读上述演示配置，简介开启，记录确认其他字段未变。
