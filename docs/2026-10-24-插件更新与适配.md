## 主题修复

1. **Passkey 2.0 原页登录**：补齐官方 `.pill-items a[href]` 委托选择器；对直接访问旧 `method=passkey` 的入口使用官方支持的链接激活方式，避开上游把 Event 当元素的按钮错误。保留旧插件原生按钮、OIDC 返回参数、保持登录和密码回退。没有另建认证协议。
2. **评论 3.4 固定链接**：PJAX 提交 History 后，向官方组件补发位置变化通知；同时覆盖退出讨论详情、去重、地址归属与销毁。真实 Back → Forward 暴露出官方组件复制旧 History 状态引发的导航问题；增量修复仅在同源／同路径／同查询的锚点变化中复用页面，并同步当前历史地址，未知跨页状态仍交给原生导航。原生回退到当前完整地址使用真正重载，避免 `popstate` 循环。引入官方按钮文字对比色，图片宽度沿用官方 100% 默认值，修正 Moments 无效的旧样式变量，并移除官方组件不消费的 `--halo-comment-*` 别名；键盘退出瞬间讨论详情后，将焦点交还可见列表，避免落到页面主体。
3. **Docsme 表格**：去掉单元格首尾内容额外间距，保留表头、边框和横向滚动；390／1440px、深／浅色及重复挂载测试通过。
4. **联系表单自动投放**：安全解析目标页 `autoContactFrom` 数据，进入投放页时挂载、离开时清除自动浮层；同 App PJAX、冷资源、导航失败回退与过期事件隔离均有真实 2.1.0 脚本回归；官方脚本首次失败后会移除失败节点并重新请求，恢复后仅保留一个实例，保留正文手动表单。
5. **历史导航回归**：新增 `verify:pjax-history`，接入 `verify:pjax-navigation` 与完整检查；涵盖复制旧状态、原生锚点、取消恢复、跨查询与未知状态回退。
6. **版本验收入口**：24 项严格 fixture 同步实际安装版本；契约验证复用该当前目标，九月报告保留历史事实，不再用九月版本阻止新契约。`contractVersion` 和 `testedVersion` 仍分开。

Passkey 专项 `pnpm run verify:auth-passkey` 使用实际安装 JAR 的前端脚本（也可用 `PASSKEY_PLUGIN_JAR` 或 `PASSKEY_PLUGIN_SCRIPT` 指定），属于本地插件集成测试，不加入无插件环境的 CI 完整检查；测试模拟认证请求和凭据边界，不冒充真实硬件通行密钥登录。联系表单专项 `pnpm run verify:contact-form:pjax` 同样读取本地实际 JAR，可用 `CONTACT_FORM_PLUGIN_JAR` 指定；只验证前端生命周期，不提交表单。Docsme 表格测试已加入完整检查。
