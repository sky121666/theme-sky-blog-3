# 主题导航契约 v1

源码标识：`@theme-navigation-contract v1`。这是主题导航实现约定，不代表某个 Halo / 插件版本已通过运行验收。插件支持范围和组合证据仍以《插件适配契约》《插件适配状态》为准。

## 职责与入口

| 模块 | 职责 |
| --- | --- |
| `src/shared/navigation-link-policy.js` | 根据当前链接和事件快照判断是否接管，无 DOM 查询和导航状态 |
| `src/shell/desktop-shell/runtime/desktop/pjax/click-controller.js` | 唯一 document 冒泡 click 入口；组件事件先运行；提供幂等 install/dispose |
| `src/shell/desktop-shell/runtime/desktop/pjax/navigation-admission.js` | 同步离页投票、一次性许可、提交前复核、原生交接许可 |
| 同目录 `index.js` | 保留 Pjax 0.2.8 full 与 same-variant 执行器、现有请求代次和历史所有权 |

页面只需输出 `a.pjax-link[href]`；可用 `data-pjax-app` 帮助资源推断。动态插入、缓存恢复和 Alpine 更新无需逐链接绑定。`data-pjax-attached` / `data-pjax-state` / `data-pjax-managed` 不再决定是否接管。

`window.pjax.attachLink(anchor)` 仅为旧调用方添加 `pjax-link`，不绑定 click/keyup。主题不提供 `attachLinks`。`loadUrl(url, options)` 是程序导航入口，默认 full；其 Promise 只表示启动或否决，不表示目标页面已就绪。

## 浏览器行为

以下交给浏览器：组件已取消的事件、非左键、修饰键、非 opt-in 链接、运行时未启动、空 href、download、非当前窗口 target（含继承的 base target）、外站 / 非 HTTP(S) 链接、同路径及查询参数的显式 hash（含空 `#`）。显式空 target 覆盖 base target。

Enter 使用浏览器产生的 click。组件 `preventDefault` / `stopPropagation` 和编辑态阻断先于导航。接管后同步阻止默认行为；离页否决不会再退回原生跳转。

## 草稿、请求和历史

1. 捕获桌面布局和主题设置的版本、保存状态、可见 / 编辑状态。所有守卫只投票。
2. 全部同意后才发送 `theme:navigation-accepted`，取得既有 intent 并开始请求；否决不抢占上一导航。
3. 有效响应及必要资源就绪后，在持久桌面协议、标题栏、插件 UI 和正文发生改变前统一复核。等待期间修改、开始保存或守卫集合变化均撤回许可，保留草稿。
4. 清理同步执行且每个许可最多一次。same→full 回退复用许可和 intent，不重复确认 / accepted / history。
5. full 响应必须恰好包含一个 title 和一个窗口根节点。缺失或重复时通过许可交给浏览器；不能先清理再发现结构异常。
6. 旧响应不能替换 DOM、结束新 loading 或发 ready。请求失败在提交前保留原内容；提交后失败进入受控恢复，不声称旧状态完整保留。

主题 popstate 准入监听必须在 Pjax 构造前注册。已知 history index 的否决使用真实差值返回源项；未知 state 不猜步数，使用 replaceState 恢复源 URL 和主题状态，无法保证保留未知历史栈形状。

尚未写入目标项的原生跳转使用 assign；已有目标项或 popstate 使用 replace。原生交接不提前丢弃草稿。两个主题 beforeunload 守卫共享一次许可；新输入、新 intent、pageshow、状态变化或 1500ms 到期使许可失效，第三方 beforeunload 仍可阻止跳转。

## 主题事件

均在 document 派发，`bubbles: true`、不可取消。外部否决继续通过 window 上可取消的 `theme:before-pjax-navigation`（`detail.url`）同步表达。

| 事件 | detail | 含义 |
| --- | --- | --- |
| `theme:navigation-accepted` | intentId, url, source | 一次获准导航；source 为 click / programmatic / popstate |
| `theme:pjax-ready` | intentId, url, appId, root, mode | 当前主题 DOM、必要资源、同步组件初始化、历史和 loading 已收尾；mode 为 full / same |
| `theme:navigation-settled` | intentId, url, outcome, reason | 每个 accepted 的唯一终态；ready / cancelled / superseded / failed / native |

ready 先于 settled(ready)。失败、撤回和被抢占的导航没有 ready。native 仅表示开始浏览器交接，不表示目标已加载。ready 不承诺评论、图片、插件业务请求都已完成。

保留库 `pjax:*`、同变体事件和 `theme:content-swapped`，供已有外部消费者使用。主题通用 UI 使用主题事件；Links 的 URL 规范化保留单一 `pjax:same-variant-complete` 同步回调，使规范化发生在 history 提交之后、ready 之前。它不作为页面就绪通知，也不重复订阅 ready。

## 验证与恢复

- 离线：`pnpm run verify:pjax-navigation`、`pnpm run check`。
- 当前本地构建：`pnpm run verify:reload`、`pnpm run verify:navigation:live`、`pnpm run verify:navigation:pages`、`pnpm run verify:pjax-cold-assets`、`SMOKE_BASE_URL=http://localhost:8090 pnpm run verify:pjax-lifecycle`、`SMOKE_BASE_URL=http://localhost:8090 pnpm run smoke:playwright`。
- 浏览器验证使用完整刷新，避免旧库匿名监听残留。报告必须记录实际 Halo / 插件、源码和构建指纹；原始报告留本地。
- 恢复顺序：先恢复 ready 发射及对应消费者，再整体恢复点击入口及消费者，最后恢复守卫及执行器提交挂点；同步重建资源。保留用户其他改动，不整仓 reset，也不启用两套点击路由。
