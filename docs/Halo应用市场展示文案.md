# Halo 应用市场展示文案

对应正式版本 `v0.9.47`，要求 Halo `>=2.26.0`。本文保存应用介绍文案，便于与 README 同步；应用市场的实际上架内容需单独核对。

## 简短介绍

macOS 桌面风格 Halo 主题，支持 Dock 与窗口浏览、系统设置预览、图片与图标选择、桌面小组件和手机端阅读。

## 应用介绍

Sky Blog 3 是面向 Halo 的 macOS 桌面风格博客主题。文章、归档和插件内容通过桌面图标、Dock、菜单栏与窗口组织，支持窗口最小化与恢复。系统设置提供外观、墙纸、导航和小组件等配置，可先查看草稿效果再应用。配合素材选择器、桌面布局编辑与手机端内容界面，让博客同时呈现个人风格和日常阅读体验。

### 从桌面开始浏览

桌面图标、Dock 与菜单栏集中组织内容入口。在窗口中浏览文章和兴趣内容，最小化后可以恢复浏览。

### 调整外观，先看效果

在分类中查找设置，预览墙纸、配色和导航变化，再决定是否应用；取消会丢弃未保存的草稿。

### 换上自己的图片与图标

通过 Halo 附件库、图片地址和 Iconify 图标配置站点品牌与桌面入口。附件上传会立即创建附件，选择素材与应用配置是后续步骤。

### 让常用内容留在桌面

添加小组件、调整尺寸和位置，将时间、天气与内容摘要排成自己的布局。需要编辑站点默认布局时，可从系统设置进入桌面管理。

### 在窗口里阅读与探索

Finder 用于归档、分类与标签浏览；阅读页提供文章目录。瞬间、图库、友链与朋友圈、追番、豆瓣、Steam、装备和 Docsme 提供对应插件内容界面。

### 在手机上专注内容

内页聚焦正文，导航、分类和搜索适应窄屏浏览。

## 安装与依赖

1. 使用 Halo `>=2.26.0`，下载 `v0.9.47` 主题 ZIP。
2. 在 Halo 后台「外观 → 主题」上传并启用。
3. 根据需要配置桌面入口、小组件和插件页面。

插件内容需要安装对应插件；搜索、评论和代码高亮由相应插件提供。系统设置和站点默认布局编辑需要主题配置权限。

完整能力、操作入口与当前限制见 [README](../README.md)、[前端系统设置](设置/前端系统设置.md)与[插件适配状态](插件适配状态.md)。
