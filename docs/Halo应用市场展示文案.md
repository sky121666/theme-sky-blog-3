# Halo 应用市场展示文案

对应版本 **v0.9.60**，基于 **Halo 2.27** 开发，最低要求 **`>=2.27.0`**。本文与 README 同步，尚未更新到 Halo 应用市场的应用简介；版本发布不自动同步应用简介。本版更新说明见[发布说明](发布说明.md#v0960)。

## 简短介绍

macOS 桌面风格 Halo 主题，支持 Dock、无刷新窗口浏览、桌面小组件、文档资料库与商城，兼顾桌面体验和手机阅读。

## 应用介绍

Sky Blog 3 是面向 Halo 的 macOS 桌面风格博客主题。文章、归档和插件内容通过桌面图标、Dock、菜单栏与窗口组织，支持窗口最小化与恢复。系统设置提供外观、墙纸、导航和小组件等配置，可先查看草稿效果再应用。配合素材选择器、桌面布局编辑与手机端内容界面，让博客同时呈现个人风格和日常阅读体验。

### 从桌面开始浏览

桌面图标、Dock 与菜单栏集中组织内容入口。Swup 负责无刷新切换与公开链接预加载，切换内容时保留桌面和小组件；窗口支持最小化与恢复。

### 调整外观，先看效果

在分类中查找设置，预览墙纸、配色和导航变化，再决定是否应用；取消会丢弃未保存的草稿。

### 换上自己的图片与图标

通过 Halo 附件库、图片地址和 Iconify 图标配置站点品牌与桌面入口。附件上传会立即创建附件，选择素材与应用配置是后续步骤。

### 让常用内容留在桌面

添加小组件、调整尺寸和位置，将时间、天气与内容摘要排成自己的布局。需要编辑站点默认布局时，可从系统设置进入桌面管理。

### 在窗口里阅读与探索

Finder 用于归档、分类与标签浏览；文章和文档优先显示正文，返回后恢复阅读位置。Docsme 提供资料库、章节树和可固定的正文目录；图库支持连续看图与右侧评论。瞬间、友链与朋友圈、追番、豆瓣、Steam 和装备提供对应插件内容界面。

### 展示商品与数字内容

配合 Halo 商城版，以 Mac App Store 风格组织探索、商品和类别；支持卡片／列表与尺寸切换，购买、结算和订单使用商城官方组件。

### 在手机上专注内容

内页聚焦正文，导航、分类和搜索适应窄屏浏览。

## 安装与依赖

1. 先升级至 Halo `>=2.27.0`，从 v0.9.60 正式 Release 下载主题 ZIP。
2. 在 Halo 后台「外观 → 主题」上传并启用。
3. 根据需要配置桌面入口、小组件和插件页面。

插件内容需要安装对应插件；搜索、评论和代码高亮由相应插件提供。系统设置和站点默认布局编辑需要主题配置权限。

完整能力、操作入口与当前限制见 [README](../README.md)、[前端系统设置](设置/前端系统设置.md)与[插件适配状态](插件适配状态.md)。
