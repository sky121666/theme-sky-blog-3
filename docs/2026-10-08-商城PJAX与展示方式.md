# 2026-10-08 商城 PJAX 与展示方式

## 当前结果

修正第一阶段商城全部使用文档导航的方案。`/shop` 五个主题页面现在兼容既有 PJAX：切换窗口内容，保留桌面及同一文档。客户中心 `/uc` 是独立应用，保持文档导航；官方业务 POST 表单保留原有 CSRF 与服务端重定向语义。

当前本地候选为 `0.9.47 / 2822e860a31b`，Halo `2.26.1`。未暂存、提交、推送或发布；真实加购、下单和付款未执行。第一阶段记录见[商城适配](2026-10-08-商城适配.md)，其中旧文档导航方案与旧构建不代表本次状态。

## 展示方式

- 保留探索首页的主推、双卡与图集。
- 提供**卡片／列表**两类布局，每类有**大／中／小**三档密度。
- 从探索切换展示方式时，目录包含当前页全部商品，免费和无图商品也保留。
- 切换布局或尺寸只修改 DOM；搜索、分类和排序经现有导航许可走 PJAX。
- 浏览器本地保存布局和尺寸；分类、分页、返回和重新进入目录时恢复。明确点击探索入口仍展示探索首屏。
- 筛选后只有少数商品时，卡片尺寸仍有区别；手机排列和列表图片尺寸跟随密度变化，无横向溢出。

## 组件与资源

根据固定官方 [shop-templates README 的二次开发说明](https://github.com/lxware-dev/shop-templates/blob/7a1fb04dd4796e412aa94fc9d19f94f45b80459b/README.md)，集成四个商城组件到独立 Shop 模块。源码及差异说明在 `src/apps/shop/commerce-ui/README.md`。

原服务 SDK 在隔离负对照中确认存在两项清理缺口：支付成功后离开仍跳旧订单；延迟商品／购物车请求在移除组件后未取消。当前实现为查询传递 signal，组件销毁取消请求与查询缓存，写请求回调检查是否仍活动，成功跳转计时器在 effect 清理时取消。SKU 大图使用组件内 dialog，销毁时关闭。

四个 Custom Elements 通过模块缓存单次注册，停止加载旧 classic `main.iife.js`。官方基础 CSS 快照和主题样式合并到 Shop CSS，离店禁用、回店启用；商城依赖没有进入 Shell 静态闭包。官方组件产生的内部链接也由局部 MutationObserver 标记为 PJAX 链接，离开时释放 observer。

未安装或分发 GPL API 客户端运行时代码，只保留已核实的接口协议值。Svelte 浏览器依赖范围固定到 `5.53.10` 的 `clsx/esm-env`，独立审查 95 个客户端运行时文件确认一致；编译器依赖不作为浏览器分发内容。许可清单有 52 项，现有许可证、发布年龄、信任与安装脚本规则保持不变。

依赖审计发现原锁文件 `source-map-js@1.2.1` 的 [GHSA-68fv-2mgg-jv7q](https://github.com/advisories/GHSA-68fv-2mgg-jv7q)，已在原依赖范围内更新到修复版本 `1.2.2`；完整图与生产图审计均为 0 条漏洞。
