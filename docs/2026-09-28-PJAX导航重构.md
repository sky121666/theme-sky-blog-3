# PJAX 导航重构（2026-09-28）

本轮按已确认的 B → A → C 顺序实施：先收紧离页守卫与提交边界，再统一链接入口，最后迁移页面就绪事件。范围为主题导航及其消费者，保留原有 full / same-variant 执行器与历史协调器。未升级依赖、Halo 或插件，未执行生产部署或推送；实现完成后按用户授权分批本地提交。

## 实际修改

| 批次 | 修改 | 影响范围 |
| --- | --- | --- |
| B：离页与提交 | 两类草稿先全部投票，响应与资源就绪后统一复核和清理；same → full 回退复用许可；原生恢复使用短期、可撤销许可 | 桌面编辑、前端设置、窗口关闭、错误恢复、前进后退 |
| A：链接入口 | 增加纯链接策略与单一 document 冒泡监听；删除逐链接绑定、动态扫描和小组件导航兜底 | Header、Dock、桌面图标、小组件、Docsme、列表动态内容及缓存恢复链接 |
| C：就绪事件 | 统一 accepted / ready / settled；只有当前导航完成 DOM、资源、组件和历史收尾后发 ready；迁移消费者并配对销毁监听 | 窗口标题栏、菜单、滚动条、桌面、Docsme、Moments、插件增强 |

只新增三个生产模块：`navigation-link-policy.js`、`click-controller.js`、`navigation-admission.js`。删除 `link-attach.js`。页面通过 `a.pjax-link[href]` 声明接管；`attachLink` 只保留添加 class 的兼容行为。

新增模块及核心挂点带 `@theme-navigation-contract v1` 标识，具体入口、事件字段、失败语义和恢复顺序见[主题导航契约](主题导航契约.md)。该标识与插件 `Contract version` 分开管理，不自动提升任何插件的 `testedVersion`。

## 验证中发现并修复

- Pjax 构造时注册的 `popstate` 监听会先于后注册的主题监听运行，导致一次历史操作两次准入；已调整注册顺序，并验证真实前进、后退与否决。
- 重复 title / 窗口根节点的响应可能过早清理源页；改为完整结构检查通过后再提交，四类异常响应均经原生交接回归。
- same-variant 导航到隐藏窗口时，目标已载入但窗口未显示；已补显式恢复显示及真实点击回归。
- 未知 history index 的离页否决会使 Online Monitor 的主题私密标记被目标状态覆盖；已在恢复源历史项前恢复主题维护的标记，并用真实浏览器回归。没有修改插件或 Halo Core。
- Moments 可选缓存写入抛出 `QuotaExceededError` 时，会跳过分页取消。已让缓存失败不阻断取消；真实模板表达式的 Chromium 故障注入先失败、修复后通过，并断言无异常外泄。
- 双端入口矩阵复现移动 Docsme 的工具栏（层级 20）遮挡侧栏（18）的“项目大厅”链接。已将移动侧栏与遮罩调整到 22 / 21，位于工具栏上方；以真实指针点击及遮罩关闭验证，不使用强制点击。

## 验收边界与恢复

- 本轮页面测试使用匿名只读浏览器；未重新验收登录、发布、评论、点赞、收藏、已读写入等业务操作。旧构建写链结果不外推到本构建。
- 浏览器移动视口不替代真机触摸；缺少的真实公式、权限、多语言 / 多版本、插件默认布局等样本仍按原记录待验。
- 双端矩阵实际覆盖 Header、Dock、桌面图标、Moments 详情与标题栏返回、Docsme 项目 / 文档树 / 正文 / 面包屑 / 项目返回、Links 视图切换、归档 / 分类 / 标签 / 作者 / Reader 元链接。桌面首页当前无可见 Links 入口，该项使用程序入口；移动端使用真实 Header 链接。Photos 详情由冷加载专项覆盖。36 个场景通过不表示全部页面与业务操作穷尽。
- 矩阵的 3 个跳过子步骤是：桌面与手机所选文档均无可见正文内链，手机所选页面无可见 TOC hash 链接。Docsme 内链及 hash 的隔离测试已通过，但不能替代这些真实页面操作。
- 未知历史项的否决使用 replaceState 恢复源页，不能保证保留未知历史栈形状。第三方 beforeunload 仍有权阻止原生交接。
- 本次只解决主题导航问题。插件后端、外部 RSS / 图片地址不列为主题代码缺陷。
- 原始日志、快照与具体内容 URL 留在本机 ignored 的 `docs/evidence/pjax-design-2026-09-28/` 和 `output/`；公共文档只保留实现与验证摘要。
- 双端入口矩阵阻断业务写请求；Halo 自动阅读计数请求仅在浏览器内存返回 204 并单列记录，不发送到服务端，不作为计数功能验收。
- 恢复时按[导航契约](主题导航契约.md#验证与恢复)配套恢复事件、入口、消费者和资源，不单独恢复某一监听器，也不覆盖用户原有改动。
