# 商城 PJAX 与展示方式修正

用户要求商城点击切换兼容 PJAX，支持卡片／列表布局及大／中／小密度。沿用商城原实施授权：仅 main、pnpm；不 Git 暂存提交推送，不真实下单支付。

## 设计

- `/shop` 的五个主题页接入既有导航许可、same-app PJAX 和后退机制；客户中心 `/uc` 继续使用独立文档边界。
- 按官方 README 的源码集成方式，将四个商城组件放入独立 Shop 模块；保留表单和 CSRF，取消在途请求与销毁后的异步回调。
- 组件通过模块缓存只注册一次，业务 CSS 合并到 Shop 样式，离店禁用、回店恢复。使用当前目标服务的已核验预编译基础 CSS，保留现有依赖信任和安装脚本规则。
- 保留探索首屏；切换到目录时展示当前页全部商品。布局和尺寸仅影响显示，偏好保存在浏览器本地，不改商品或后台配置。

## 结果

候选 `0.9.47 / 2822e860a31b`：68项Node、24项自有DOM、18场景展示、8场景140项PJAX组件生命周期、8场景124项交易布局通过。真实分类/详情/返回/后退文档marker不变；手机无溢出。check/reload/依赖审计通过，全站smoke仍受同一外部favicon ORB影响。无真实业务写入或Git操作。

实现补充：复制官方允许集成的UI源码并擦除类型；以局部dialog替代没有完整destroy的mediumZoom。复用目标官方预编译CSS，避免引入无关Sass安装脚本；信任/年龄/安装脚本规则无变化。分发范围准确区分Svelte客户端运行时与编译器。source-map-js在原范围升级1.2.2解决既有审计项。少量商品卡片自动填充列，尺寸仍可区分；列表显式网格行与CTA列避免覆盖。
