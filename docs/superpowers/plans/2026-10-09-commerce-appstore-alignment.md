# 商城 App Store 对齐实施

沿用已确认的[设计审查](../../../output/appstore-alignment-audit-2026-10-08/report.md)及用户“开始适配”授权。

## 范围与约束

- 分类标题、导航状态、返回来源及滚动位置；统一搜索和筛选动作。
- 一行目录工具栏，保留卡片／列表 × 大／中／小；探索无展示切换。
- 后台配置首页主推、推荐双卡、紧凑商品行和图集，配置和前台系统设置对齐。
- 宣传图与商品身份图分工；数字／实物详情按实际商品类型显示。
- 完整分类入口与后台精选分类继续保留；全局简介开关继续生效。
- 只在当前 `main` 修改，使用 `pnpm`；不暂存、提交、推送，不真实交易。
- 不猜商品 Finder／API。只有目标商城已确认的公开读取能力可进入实现。

## 分工与接口

1. 导航代理：`model/runtime/display-runtime`、`sidebar`、新 `toolbar`，对应测试。返回链接使用 `data-shop-return`；尺寸下拉使用 `data-shop-display-size-select`。
2. 首页代理：商城设置及前台 schema／资源选择，新 `home` 模板，真实商品读取契约与测试。
3. 媒体代理：Shop CSS、`product/categories`，新媒体 helper 与布局测试。详情提供商品类型与 ID 属性。
4. 主代理：`products` 集成、当前页标题、价格范围、配置真实回读、完整构建／重载／真页验收与文档。

模板分片保持已有 PJAX 页面协议；生命周期监听器必须可清理。各代理不得构建生成资产，由主代理统一处理。
