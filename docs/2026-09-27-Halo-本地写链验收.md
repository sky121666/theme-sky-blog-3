## 环境与结论边界

本记录是[上一构建的只读验收](2026-09-27-主题三后续只读验收与目录修复.md)之后的增量验证。对象是本机 `http://localhost:8090` 的活动主题 Sky Blog 3 `0.9.46 / acc35d74a2e5`、Halo `2.26.1`；站点安装 45 个插件（44 个 `STARTED`、1 个 `DISABLED`），其中主题目标的 24 个精确版本通过 `pnpm run audit:plugins:strict`。运行验证只对这组环境、当前代码和下述业务路径成立。主题声明的 Halo 最低版本为 `>=2.26.0`，本轮没有单独运行 `2.26.0`。逐插件官方版本与最低 Halo 依据见[版本核验表](2026-09-25-插件适配核验.md)，逐页面的历史证据仍按各自构建读取。

这次本地写入经用户明确授权，只创建可识别的测试文章、动态、评论/回复、投票及一次临时主题设置，再按对象身份清理或恢复。没有升级 Halo/插件、改 Halo Core、操作生产站点、迁移数据，或执行 Git 暂存、提交、推送。主题代码仅修正 [PluginLinks 申请页](../templates/modules/links-app/list.html)两处文案：`linkApplicationEnabled=false` 时准确说明访客生成留言草稿而不提交审核，开关为 `true` 时保留正式申请文案。本机开关保持 `false`，未为测试改变其全局设置。

## 未清理对象与异常

- **待处理：一条孤立 Counter。** 清理动态后，未过滤 Counter 列表仍含 `moments.moment.halo.run/moment-1790518293417-pu7p0jub`，`upvote=1`。原始名称含 `/`；对直接路径发起读取返回 404，对 `%2F`、`%2f` 和 `%252F` 路径发起读取返回 400。Halo 2.26.1 的[扩展删除路由](https://github.com/halo-dev/halo/blob/v2.26.1/application/src/main/java/run/halo/app/extension/router/ExtensionDeleteHandler.java#L24-L37)以单个 `{name}` 路径变量取对象；源码另有[内部 `CounterService.deleteByName`](https://github.com/halo-dev/halo/blob/v2.26.1/application/src/main/java/run/halo/app/core/counter/CounterServiceImpl.java#L45-L48)。据源码和本机 HTTP 结果推断，当前公开 HTTP 路由无法安全精确删除该名称。没有改数据库、部署服务端补丁、安装辅助插件、改名或用反向点赞掩盖残留；需要另行确定服务端维护方式及授权。
- **Halo Console 内容 GET 异常。** `/apis/api.console.halo.run/v1alpha1/posts/{name}/content` 对专用文章和一篇既有公开文章均返回 500；同两篇文章的 `head-content`、`release-content` 返回 200。专用文章通过完整 Content PUT、重新发布完成投票块验收。现有证据只定位到该 Console API 路径，不能归因于主题，也不能据此声称 Halo 所有内容 API 故障。
- VoteData 的 `fieldSelector=voteName==...` 本机返回空列表，但未过滤列表能找到专用记录；清理检查因此以未过滤列表和精确名称为准。
- 评论和回复的对象已删除；组件提交时 `allowNotification=true`，可能触发过通知或邮件。本轮没有证据证明这类外部副作用可撤销，不能把“内容对象已清理”写成所有副作用均回滚。

最终只读扫描中，专用 Post、Moment、Comment、Reply、Vote、VoteData 均无匹配对象；文章和动态公开页均为 404；主题配置等于基线。唯一已知测试对象残留是上述 Moment Counter。
