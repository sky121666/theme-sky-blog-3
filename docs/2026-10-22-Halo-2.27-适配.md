# Halo 2.27 适配记录

## 目标与来源

目标为 Halo **2.27.0** 正式版（2026-10-14），本轮只修改工作区并做隔离验证。主题版本仍为 `0.9.49`，不是新的正式发布。

- 核心：[v2.27.0](https://github.com/halo-dev/halo/releases/tag/v2.27.0)，提交 `ab7810d390e3bfa00d3def619405611229aaf1ba`。
- 商城：[`release/2.27` 的固定源码](https://github.com/lxware-dev/shop-templates/tree/2e03340ca650595b3f3d98a12c6b6be3cc764607)，提交 `2e03340ca650595b3f3d98a12c6b6be3cc764607`。
- 商城 API：[Paid OpenAPI 2.27.0](https://github.com/halo-dev/swagger-api-online/blob/89b2453a69ca5f5e5a8ee605fd687d7a14472c16/src/assets/api-docs-paid/2.27/aggregated.json)。前台 `/shop` 路由以固定模板源码为准，这些路由没有全部收录于 OpenAPI。
- 评论：[官方固定链接协议](https://github.com/halo-dev/halo/blob/v2.27.0/docs/developer-guide/comment-permalinks.md)。

2026-10-22 只读访问本地 `http://localhost:8090/`，HTTP 200，页面 generator 仍为 **Halo 2.26.1**。没有升级服务、重载主题、提交、推送或部署；不能把下面的模拟测试登记为真实 2.27 验收。

## 新旧版本兼容

最低 Halo 仍为 `>=2.26.0`。官方 `#halo.matchVersion()` 自 2.25 已提供；通过 `site.version` 排除会匹配所有范围的开发版本 `0.0.0`，再判断 `>=2.27.0`。

- 2.27：使用商品 `permalink` 与前台交易访问通道。
- 2.26：商品 ID 链接、原有 UC 交易接口；不会把旧 DTO 缺少属性当作普通 null。
- 订阅、匿名订单和新版评论定位需要对应的 2.27 服务能力。

现有 Finder、菜单 `status.href`、主题 `json-config` 无需改写。商城侧栏头像使用 `contributorFinder`，未受 UC 用户返回结构变化影响。2.27 用户中心上传需配置「附件配置 → 个人中心附件配置」；本轮未修改站点配置。

## 验证

新增入口：`pnpm run verify:halo:227`，已接入 `pnpm run check`。先生成当前资源，再执行离线测试；所有商城请求由本地 fixture 拦截，没有真实 API 回退。

真实 Thymeleaf 测试通过显式 classpath 运行：

```bash
java --class-path "$SHOP_TEMPLATE_JAVA_CLASSPATH" scripts/fixtures/ShopPermalinkTemplateFixture.java .
java --class-path "$SHOP_TEMPLATE_JAVA_CLASSPATH" scripts/fixtures/ShopOrderTemplateFixture.java .
```

旧商品使用运行 JAR 中真实的 2.26 `ProductResponse`，新商品使用按 2.27 契约构造的类型。运行 JAR 不进入仓库或安装包。编译组件截图和结果保存在本地 `output/halo-2.27-compat/`；不作为真实站点截图宣传。
