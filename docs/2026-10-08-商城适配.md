## 实现

- 新增独立 `shop` App，JS/CSS 通过 App manifest 按页面加载，不加入 Shell 的静态依赖闭包。
- 列表从真实 `productPage.items` 和分类树生成主推、双卡、图集及目录；价格为 0 时正常显示，不制造评分和销量。
- 自有图册与筛选监听器随 App 释放；商品搜索、分类、排序和分页保留条件，切换条件时重置页码。
- 详情保留官方 `shop-buy-box`；交易保留 `shop-page-cart`、`shop-page-checkout`、`shop-page-payments` 以及 CSRF、结算上下文、订单标识。
- 进入或离开 `/shop`、目标客户中心使用完整文档导航，经现有导航许可后执行，避免经典 IIFE 重复注册和跨文档残留。
- 后台和前台系统设置共享 `shop.display.show_description`、`shop.display.dock_entry_enabled`。入口去重不修改用户菜单。
- 手机窗口填满内容区，导航抽屉支持焦点和 Escape；购买按钮保持底部可见，窗口打开时手机 Dock 隐藏，关闭窗口后恢复。

[功能说明与截图](商城/README.md)。本机完整日志、源码基线和报告位于 `output/commerce-adaptation-2026-10-08/`，不要求新检出环境拥有这些本机证据。

```bash
pnpm run check

pnpm run verify:commerce
pnpm run verify:commerce:transactions
pnpm run verify:commerce:ssr -- --demo-records output/commerce-adaptation-2026-10-08/demo-records.json
```

`verify:commerce:transactions` 只读获取本地官方前台资源后，在隔离浏览器中执行；所有 API 响应来自本地样例。SSR 专项需要指定有效 DEMO 记录，没有记录时明确跳过。模板修改后执行重载；遇到旧页面缓存时用当前资源指纹核对，再重新加载页面。

恢复时只恢复本次源码及对应生成资源，保留原有未提交修改；本机 `output/commerce-adaptation-2026-10-08/before/` 保存修改前文件。新增 DEMO 数据的清理属于独立删除操作。
