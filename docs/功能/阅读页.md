## 功能边界

访客从文章列表或桌面入口打开文章后，可用目录跳到正文标题、用「上一篇」「下一篇」继续阅读；目录与相邻文章入口以页面实际内容为准。文章提供点赞操作，评论区仅在站点评论组件可用且允许评论时显示；否则页面给出评论关闭或组件不可用的提示。独立单页也使用阅读页壳层，但不应假定每个单页都有文章的目录、上下篇或点赞。点赞与评论是否成功由对应服务端接口和账号权限决定，界面点击不等于服务端已写入。

阅读页 App 负责：

- 文章正文壳
- 目录
- 点赞
- 评论区容器
- 上下篇导航

不负责：

- 顶栏
- Dock
- 主窗口壳层
- PJAX 总线

这些仍由 `desktop-shell` 负责。

## 什么时候改这里

这些需求应该优先改阅读页 feature：

1. 正文排版
2. 目录行为
3. 点赞逻辑
4. 评论区容器样式
5. 上下篇卡片

## 我想配什么，先配哪里

阅读页本身没有单独主题设置组。
如果你只是想影响阅读页外围行为，优先检查：

1. 评论组件颜色变量：看 shell token
2. 分享与标题栏行为：看 [/docs/功能/桌面壳层.md](桌面壳层.md)
