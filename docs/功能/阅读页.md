## 功能边界

直接访问文章时，服务端输出可见正文，不依赖桌面脚本或开机遮罩结束；文档正文遵循相同原则。窗口管理器就绪后接管已记住的尺寸和位置，从其他窗口后退时恢复阅读区滚动位置。

文章封面优先加载，正文显示不等待封面。经 Swup 打开文章时，为适用的非首张普通正文图片补充原生懒加载；保留显式加载策略、链接和插件接管的图片。普通直达保留编辑器原始标记，不声称全部历史图片都已转换。图片灯箱支持键盘打开、关闭回焦；实际范围见[窗口媒体验收](../2026-11-17-窗口媒体与版本验收.md)。

评论分页、固定链接与浏览器历史由主题和官方组件共同衔接。离开未保存评论时先确认；取消或导航失败保留草稿，在请求期间继续输入也会重新检查。微信／QQ 分享使用目标页面的官方签名信息更新，详细边界见[插件适配契约](../插件适配契约.md)。

文章点赞在请求中防止重复点击，15 秒未确认时结束等待。网络中断、超时或服务端 5xx 会保留「等待确认」提示，要求刷新核对，避免重发可能已成功的点赞；明确成功才更新计数并记住已点赞。离开文章会取消当前请求并清理提示计时器。正常／异常行为的受控测试与真实界面操作见[文档体验与全局续审](../2026-11-16-文档体验与全局续审.md)，该验收没有向真实文章提交点赞。

访客从文章列表或桌面入口打开文章后，可用目录跳到正文标题、用「上一篇」「下一篇」继续阅读；目录与相邻文章入口以页面实际内容为准。文章提供点赞操作，评论区仅在站点评论组件可用且允许评论时显示；否则页面给出评论关闭或组件不可用的提示。独立单页也使用阅读页壳层，但不应假定每个单页都有文章的目录、上下篇或点赞。点赞与评论是否成功由对应服务端接口和账号权限决定，界面点击不等于服务端已写入。

阅读页 App 负责：

- 文章正文壳
- 目录
- 点赞
- 评论区容器
- 上下篇导航

不负责：

- 顶栏
- Dock
- 主窗口壳层
- PJAX 总线

这些仍由 `desktop-shell` 负责。

## 什么时候改这里

这些需求应该优先改阅读页 feature：

1. 正文排版
2. 目录行为
3. 点赞逻辑
4. 评论区容器样式
5. 上下篇卡片

## 我想配什么，先配哪里

阅读页本身没有单独主题设置组。
如果你只是想影响阅读页外围行为，优先检查：

1. 评论组件颜色变量：看 shell token
2. 分享与标题栏行为：看 [/docs/功能/桌面壳层.md](桌面壳层.md)
