# 友链功能：路由与参数开发文档

## 1. 文档范围

本文只描述友链功能的页面路由、查询参数、权限、数据请求和状态规则，不描述页面布局、颜色、动画或响应式样式。

当前实现基线：

- 页面入口：`/links`
- 页面模板：`templates/links.html`
- 功能模板：`templates/modules/links-app/list.html`
- 页面运行时：`src/apps/links/runtime.js`
- 插件契约：`PluginLinks 2.2.1`
- 留言能力：可选依赖 `PluginCommentWidget 3.1.2`
- 旧 `plugin-friends`、`link-submit` 及 `/friends` 不属于当前主题契约

所有功能共用 `/links`，通过查询参数恢复具体状态。页面 SEO canonical 始终为 `/links`。

## 2. 功能清单

当前友链模块提供以下功能：

1. 浏览全部友链。
2. 按 PluginLinks 分组筛选友链。
3. 通过链接资源名打开指定友链详情。
4. 浏览已开启公开 RSS 的友链来源。
5. 查看全部、分组或单一来源的 RSS 动态。
6. 对有权限的登录用户提供未读、收藏、稍后阅读和 RSS 内部详情。
7. 对有权限的登录用户保存已读、收藏和稍后阅读状态。
8. 自动识别待添加站点的名称、描述、Logo 和 RSS 地址。
9. 有管理权限时直接创建 Link 资源；访客、无权限用户和修改申请生成留言内容。
10. 通过 PluginCommentWidget 承载友链申请和普通留言。

## 3. 页面路由总表

| 功能 | 规范路由 | 权限 |
| --- | --- | --- |
| 全部友链 | `/links` | 公开 |
| 友链分组 | `/links?group={group}` | 公开 |
| 友链详情 | `/links?link={link}` | 公开 |
| 指定分组中的友链详情 | `/links?group={group}&link={link}` | 公开 |
| RSS 来源总览 | `/links?view=friends` | 公开 |
| 全部 RSS 动态 | `/links?view=friends&scope=all` | 公开；登录后可自动使用受保护数据源 |
| 未读动态 | `/links?view=friends&scope=unread` | `plugin:links:view` |
| 收藏动态 | `/links?view=friends&scope=favorite` | `plugin:links:view` |
| 稍后阅读 | `/links?view=friends&scope=later` | `plugin:links:view` |
| RSS 分组动态 | `/links?view=friends&groupName={groupName}` | 公开；是否有数据取决于 RSS 公开设置 |
| 单一 RSS 来源 | `/links?view=friends&linkName={linkName}` | 公开；是否有数据取决于 RSS 公开设置 |
| RSS 内部详情 | 在有效 RSS 动态路由后追加 `&itemId={itemId}` | `plugin:links:view` |
| 添加或申请友链 | `/links?view=apply` | 公开；直连创建需要 `plugin:links:manage` |
| 留言板 | `/links?view=board` | 页面公开；实际留言依赖 PluginCommentWidget |

示例：

```text
/links?group=link-group-friends
/links?link=link-example
/links?group=link-group-friends&link=link-example
/links?view=friends&scope=all
/links?view=friends&groupName=link-group-friends
/links?view=friends&linkName=link-example
/links?view=friends&scope=favorite&itemId=feed-item-id
```

示例中的资源名仅用于说明格式，实际值必须来自当前 Halo 站点。

## 4. 页面查询参数

页面运行时只管理以下 7 个查询参数。

| 参数 | 可选值或来源 | 作用 | 适用上下文 |
| --- | --- | --- | --- |
| `view` | `friends`、`apply`、`board` | 切换到 RSS、添加申请或留言状态 | `/links` |
| `group` | `LinkGroup.metadata.name` | 筛选普通友链分组 | 默认友链状态 |
| `link` | `Link.metadata.name` | 选择一条普通友链 | 默认友链状态 |
| `scope` | `all`、`unread`、`favorite`、`later` | 选择 RSS 聚合范围 | `view=friends` |
| `groupName` | RSS 来源所属 `LinkGroup.metadata.name` | 只读取一个分组的 RSS 动态 | `view=friends` |
| `linkName` | 启用 RSS 的 `Link.metadata.name` | 只读取一个友链来源的 RSS 动态 | `view=friends` |
| `itemId` | PluginLinks RSS 条目 `id` | 在当前 RSS 结果中选择内部详情 | 有效 RSS 动态上下文 |

补充规则：

- 默认友链状态不写 `view`；`view=links` 不是规范参数，会被还原为 `/links`。
- `group`、`groupName` 和 `linkName` 使用的是资源名，不是展示名称。
- `link` 使用 Link 资源名，不使用友链 URL 或展示名称。
- `itemId` 只是页面选择状态，不会调用独立的“按 ID 查询详情”接口。目标条目必须已存在于当前加载结果中。
- 页面搜索词、排序状态、表单内容和 RSS 分页游标不写入页面 URL。
- 参数值由 `URLSearchParams` 编码；调用方不要手工拼接未编码的资源名。

## 5. 参数组合与互斥规则

### 5.1 默认友链状态

- 允许无参数、仅 `group`、仅 `link`，或同时包含 `group` 和 `link`。
- `group` 和 `link` 同时存在时，目标 Link 必须属于该 LinkGroup。
- 如果 Link 存在但不属于指定分组，运行时保留 `link`、移除 `group`。
- 不存在的 `group` 或 `link` 会在首屏初始化后从规范 URL 中移除。
- 默认友链状态不接受 `scope`、`groupName`、`linkName`、`itemId`。

### 5.2 RSS 状态

- RSS 状态必须显式包含 `view=friends`。
- `scope` 与 `groupName`、`linkName` 互斥。
- `groupName` 与 `linkName` 同时出现时，`groupName` 优先，`linkName` 被移除。
- 当 `groupName` 或 `linkName` 存在时，`scope` 被移除。
- `itemId` 必须和有效的 `scope`、`groupName` 或 `linkName` 一起使用；孤立的 `itemId` 会被移除。
- `scope=unread`、`favorite`、`later` 是受保护语义，URL 本身不授予权限。

### 5.3 添加与留言状态

- `view=apply` 和 `view=board` 不接受其他友链或 RSS 状态参数。
- 与它们同时出现的 `group`、`link`、`scope`、`groupName`、`linkName`、`itemId` 会被移除。

### 5.4 非法参数恢复

首屏初始化会用 `history.replaceState` 规范化已识别的非法组合：

- 未知 `view` 回退到默认友链状态。
- 未知 `scope` 被移除。
- 不存在的 `group`、`link` 被移除。
- 不适用于当前 `view` 的参数被移除。
- 友链模块不认识的其他查询参数和 URL hash 会被保留。

主题内部切换使用 `history.pushState`；浏览器前进、后退通过 `popstate` 恢复状态，不需要整页刷新。

## 6. RSS 首屏与分页规则

### 6.1 服务端首屏

模板首先调用：

```text
linkFeedFinder.groupBy(1)
```

只有存在公开 RSS 来源，且路由满足以下任一条件时，服务端才预取首批 20 条公开动态：

- `view=friends&scope=all`
- `view=friends&groupName={groupName}`
- `view=friends&linkName={linkName}`

对应 Finder 调用：

```text
linkFeedFinder.list({ limit: 20 })
linkFeedFinder.list({ limit: 20, groupName })
linkFeedFinder.list({ limit: 20, linkName })
```

`/links?view=friends` 只读取 RSS 来源分组，不预取动态正文。`unread`、`favorite`、`later` 不在服务端读取，因为它们依赖当前登录用户权限和状态。

### 6.2 客户端续载

RSS 页面每次请求 20 条，使用 PluginLinks 返回的复合游标续载：

- `beforePublishedAt`
- `beforeId`

这两个参数只发送给 RSS API，不进入页面 URL。API 返回：

- `nextBeforePublishedAt`
- `nextBeforeId`
- `hasNext`

运行时仅在 `hasNext=true` 且至少一个下一页游标存在时继续加载。通用 URL 构造器会把 `limit` 约束到 `1..100`，页面固定使用 `20`。

## 7. 权限模型

页面先读取当前 Halo 用户，再读取该用户的 UI 权限：

```text
GET /apis/api.console.halo.run/v1alpha1/users/-
GET /apis/api.console.halo.run/v1alpha1/users/{username}/permissions
```

能力映射：

| 能力 | 权限或兼容角色 | 功能 |
| --- | --- | --- |
| RSS 状态读取 | `plugin:links:view` 或 `role-template-link-view` | 受保护 RSS 列表、未读、收藏、稍后阅读、内部详情、状态写入 |
| 链接管理 | `plugin:links:manage` 或 `role-template-link-manage` | 包含 RSS 状态读取，并允许官方识别和直接创建 Link |

`plugin:links:manage` 在前端能力模型中隐含 `plugin:links:view`。最终写入仍由 Halo 服务端权限和 CSRF 校验决定，前端判断不是安全边界。

访客或权限不足时：

- 仍可浏览普通友链和插件允许公开的 RSS 动态。
- 不能读取个人未读、收藏或稍后阅读状态。
- `favorite`、`later` 深链会回退到全部动态。
- `unread` 深链没有受保护权限时不会获得未读过滤；调用方不应向访客生成该链接。
- 不能调用受保护的官方识别和写入能力。

## 8. RSS API 与参数映射

### 8.1 公共 RSS 列表

```text
GET /apis/api.link.halo.run/v1alpha1/linkfeeds
```

请求使用 `credentials: omit`，不携带 Halo 登录态。

| API 参数 | 类型 | 作用 |
| --- | --- | --- |
| `groupName` | string | 按 LinkGroup 资源名筛选 |
| `linkName` | string | 按 Link 资源名筛选；与 `groupName` 互斥 |
| `beforePublishedAt` | string | 下一页发布时间游标 |
| `beforeId` | string | 下一页 ID 游标 |
| `limit` | integer | 每页数量，页面固定为 20 |

公共 RSS 是否可用由 PluginLinks 的 RSS 公开设置决定；关闭时接口可能返回 `404`。

### 8.2 受保护 RSS 列表

```text
GET /apis/console.api.link.halo.run/v1alpha1/rss/items
```

请求使用当前 Halo 会话。除公共列表参数外，还支持以下状态筛选：

| 页面参数 | API 参数 |
| --- | --- |
| `scope=unread` | `read=false` |
| `scope=favorite` | `favorite=true` |
| `scope=later` | `readLater=true` |
| `scope=all` | 不发送状态筛选参数 |

未读统计：

```text
GET /apis/console.api.link.halo.run/v1alpha1/rss/items/-/unread-summary
```

前端读取响应中的 `totalUnreadCount`。

### 8.3 RSS 状态写入

以下请求需要当前 Halo 会话、`plugin:links:view` 和 CSRF 令牌：

```text
POST /apis/console.api.link.halo.run/v1alpha1/rss/items/{id}/read?read={true|false}
POST /apis/console.api.link.halo.run/v1alpha1/rss/items/{id}/favorite?favorite={true|false}
POST /apis/console.api.link.halo.run/v1alpha1/rss/items/{id}/read-later?readLater={true|false}
```

打开 RSS 内部详情时：

1. 未读条目自动写入 `read=true`。
2. 如果条目处于稍后阅读，同时写入 `readLater=false`。
3. 收藏状态不自动改变。
4. 用户仍可手动切换已读、收藏和稍后阅读状态。

## 9. 站点识别与友链提交

`view=apply` 不使用额外页面查询参数。表单数据只存在于当前页面状态，刷新后不通过 URL 恢复。

### 9.1 表单字段

| 字段 | 用途 | 是否写入 Link 资源 |
| --- | --- | --- |
| `type` | `add` 新增或 `update` 修改申请 | 否 |
| `displayName` | 站点名称 | `spec.displayName` |
| `url` | 站点地址，仅接受 HTTP/HTTPS | `spec.url` |
| `logo` | Logo 地址，仅接受 HTTP/HTTPS | `spec.logo`，可选 |
| `description` | 站点描述 | `spec.description` |
| `groupName` | LinkGroup 资源名 | `spec.groupName`，可选 |
| `rssUrl` | RSS/Atom 地址 | `spec.rss.enabled=true` 与 `spec.rss.feedUrls[0]`，可选 |
| `email` | 留言申请的联系邮箱 | 否 |
| `updateDescription` | 修改申请说明 | 否 |

### 9.2 管理员官方识别

仅在能力判断得到 `plugin:links:manage` 后调用：

```text
GET /apis/console.api.link.halo.run/v1alpha1/links/-/detail?url={url}
GET /apis/console.api.link.halo.run/v1alpha1/rss/discovery?url={url}
```

识别结果映射：

- `title` -> `displayName`
- `description` -> `description`
- `icon` 或 `image` -> `logo`
- `feedUrls[0]` -> `rssUrl`

如果官方识别失败，运行时尝试降级到浏览器公开识别。

### 9.3 浏览器公开识别

访客和无管理权限用户直接对目标 URL 发起匿名跨域 `GET`：

- `credentials: omit`
- `cache: no-store`
- 最长等待 8 秒
- 最大读取 1,500,000 字节
- 只接受 HTML/XHTML
- HTTPS 页面拒绝读取 HTTP 目标，避免混合内容

识别以下公开元数据：网页标题、描述、图标、RSS/Atom 地址和 `generator`。该请求受目标站 CORS 和访问策略限制，不保证成功。

### 9.4 管理员直接创建

仅 `type=add` 且拥有管理能力时调用：

```text
POST /apis/core.halo.run/v1alpha1/links
```

请求使用当前 Halo 会话，发送 JSON Link 资源，并携带 `X-XSRF-TOKEN`。资源名由服务端根据 `generateName: link-` 生成。

修改申请不会直接更新已有 Link。`type=update` 始终生成 Markdown，由管理员审核后处理。

### 9.5 访客与降级申请

PluginLinks 没有匿名创建 Link 的公共接口。以下情况只生成 Markdown，不调用受保护写入接口：

- 未登录访客。
- 已登录但没有管理权限。
- 权限检查或直接创建返回 `401`、`403` 后的安全降级。
- 所有修改申请。

复制成功后，页面切换到 `/links?view=board`。留言实际由 PluginCommentWidget 提交；组件目标为：

```text
group = plugin.halo.run
kind  = Plugin
name  = PluginLinks 提供的 pluginName
```

PluginCommentWidget 未安装时，`view=board` 仍可打开，但不能提交留言。

## 10. RSS 数据字段

运行时消费的 RSS 条目字段：

```text
id
linkName
url
title
summary
author
authorUrl
authorLogo
publishedAt
fetchedAt
updatedAt
read
favorite
readLater
```

其中 URL 仅接受 HTTP/HTTPS，文本字段在进入页面状态前会转为纯文本。没有合法 `url` 的条目会被丢弃。

## 11. 外部深链与兼容边界

- 桌面朋友圈小组件统一跳转到 `/links?view=friends`。
- 当前主题不提供 `/friends` 页面兼容。
- 当前主题不调用 `plugin-friends` API。
- 当前主题不调用 `link-submit` 匿名提交 API。
- 不存在通过 URL 参数手动选择“前端识别”或“后端识别”的模式；系统按登录权限自动选择并在失败时降级。
- `LINK_MANAGE_API` 常量目前未参与实际创建流程；真实创建端点是 Halo 标准 `core.halo.run/v1alpha1/links`。
