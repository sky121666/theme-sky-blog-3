# Docsme 项目入口的规范地址

文档项目入口是动态地址，默认章节、版本或语言可以变化。它与直接访问章节是两种有效入口；主题不重定向，也不把某个站点当前的首章硬编码进布局。

| 站点状态 | 规范地址的来源 |
| --- | --- |
| SEO 工具集已启用 | 保留插件在原始 HTML 中的 canonical。项目入口和章节的地址可以不同。插件若关闭该标签，主题不会在脚本启动后擅自补回。 |
| 没有启用 SEO 工具集 | 正文与目录取 Docsme 的 `docTree.status.permalink`，资料库取 `/docs`；在服务端生成 canonical 和对应的分享地址。 |

初次加载、浏览器后退和 Swup 导航都保留同一来源。应用不能因为当前显示的是某一章就重写项目入口的 canonical。插件输出的结构化数据可以描述实际章节，并不要求其所有 URL 都等于项目入口。

## 验证

使用普通 GET 检查项目入口和章节，分别对比关闭 JS、正常初始化和 Swup 导航后的 head。8090 使用 SEO 工具集，`node scripts/verify-reading-entry-live.mjs` 验证该分支。无插件的站点可用 `READING_SEO_PROVIDER=theme` 和对应的公开测试路由运行同一验收；离线的 `pnpm run verify:seo-contract` 覆盖两种来源和插件关闭 canonical 的情况。
