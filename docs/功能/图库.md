## 浏览与图片加载

- 从相册进入详情后，通过胶片条或方向键切换照片；评论输入和其他控件正在处理键盘时不触发切图。
- 切换窗口不等待原图。原图较慢时先显示可用预览，仍可缩放、拖动和返回；失败后在图片区域重试。
- 列表和胶片条优先使用配置的封面，详情保留原件。动态大图可在插件后台另设静态封面；主题不会自动为所有图片生成缩略图。
- 工具栏打开信息或右侧评论面板；手机使用抽屉。关闭后恢复入口焦点，编辑器已处理的按键不再触发外层关闭。
- 列表续页失败保留已有照片和重试入口；离开页面或快速切图时，过期请求不能覆盖当前照片。

## 当前验收边界

2026-11-17 在 8090 / Halo `2.27.3` 完成桌面、390px 和 320px 的相册、详情、缩放、信息、评论编辑框与返回操作。慢原图、封面选取及失败恢复见[窗口媒体验收](../2026-11-17-窗口媒体与版本验收.md)；实际评论提交、后台上传删除和真机触摸不由本轮公开界面检查证明。

图库列表和详情的主题契约均是 `PluginPhotos 2.1.1`；旧报告在安装的 `2.1.2` 上做过页面兼容回归，但逐 surface 权威表两行的 `Tested version` 仍为 `—`，本页不把旧 smoke 自动登记为完整范围的真页 testedVersion。列表使用服务端 `photos` / `groups` / `photos.nextUrl` 与 HTML 续页，详情使用 `PhotoVo`、`neighbors`、EXIF；公共 REST 只作过只读评估。后台上传删除、评论提交、全部媒体和真机触摸未验收。源码见 `src/apps/photos/runtime/explorer.js` 与 `templates/{photos,photo}.html`。

## 结论

图库是一个独立 App，协议名是：

- `pageApp = photos`
- `pageMode = browser-list`
- `windowVariant = photos`

它不是 explorer 的样式分支，也不是 reader 的特例。

## 插件契约

当前主题对 `PluginPhotos` 拆成两个 surface 记录：

1. `/photos` 列表、分页、分组、精选集：契约版本为 `PluginPhotos` 2.1.1，历史兼容回归使用 2.1.2，后续版本与测试范围见适配契约。
2. `/photos/{name}` 详情：继续按 2.1.1 的 `PhotoVo`、`neighbors`、`photoUrl.detail(...)`、`backUrl`、`exif` 和 `spec.tags` 适配，已由 Playwright 自动发现并打开 2.1.2 的真实照片详情。

列表页已消费的关键模板变量：

- `groups`
- `photos`
- `photoUrl.detail(photo)`
- `photos.nextUrl`
- `group`
- `page`
- `size`

## 公共 REST 增强评估

`PluginPhotos` 2.1.2 继续提供公共 REST 查询能力，但当前主题暂不切换到 REST 渲染。

| 能力 | 本地结果 | 判断 |
| --- | --- | --- |
| `/apis/api.photo.halo.run/v1alpha1/photos` | 200，当前 46 张照片 | 可作为未来无刷新分页或详情预取的数据源 |
| `ungrouped=true` | 200，当前 0 条 | 暂无入口价值 |
| `tag=<name>` | 200，当前没有 tag 样本 | 暂无入口价值 |
| `/apis/api.photo.halo.run/v1alpha1/photogroups` | 200，当前 4 个分组 | SSR/Finder 已覆盖分组展示 |
| `/apis/api.photo.halo.run/v1alpha1/photos/tags` | 404 | tag 列表不是公共端点，不作为主题前台依赖 |

当前结论：

1. 保持 SSR/Finder 和 HTML 下一页加载，不改成全前端 REST 渲染。
2. 已识别的公开详情链接使用统一 HTML 意图预取；尚未新增 REST 详情预取、tag 视图或 ungrouped 入口。
3. 未来如果要做 REST 增强，应先补 tag/ungrouped 样本，再用浏览器验证 LCP、CLS、图片 lazy 和 PJAX 状态。

## 壳层联动

图库有自己的窗口标题栏协议字段：

- `data-photos-chrome-title`
- `data-photos-chrome-subtitle`

用于：

- 首屏标题
- same-variant 切换后的标题同步
- 浏览器历史回退后的 chrome 恢复

## 什么时候改图库

这些需求应该优先改图库 App：

1. 图库卡片样式
2. 标题栏 `+/-`、布局模式按钮
3. 精选集样式
4. 相册侧边栏显示
5. 图库分页与滚动

不要把图库样式重新挂回 explorer。
