# 装备

## 界面截图

[查看装备编号截图图集](装备/截图.md)：装备列表、单个装备分组。交互与写入验收范围见本页说明。

## 能力与入口

安装并启用 `equipment` 插件，创建装备分组及条目后，可在 `/equipments` 浏览。主题使用插件服务端数据与 Finder 输出，包含分组侧栏、封面、规格、描述、外链和自动续载。

| 操作 | 当前行为 |
| --- | --- |
| 查看全部 | 打开 `/equipments`，显示全部装备及总数 |
| 切换分组 | 点击左侧分组，地址使用 `?group=<metadata.name>`；显示分组名称、说明和数量 |
| 浏览下一页 | 接近列表底部时续载服务端给出的 HTML 下一页；请求中禁止重复触发 |
| 访问装备链接 | 有 `spec.url` 时装备名称在新标签页打开；没有地址时只展示名称 |
| 调整主题标题和简介 | 系统设置「应用 → 装备」，或后台 `equipments.profile.display_name`／`subtitle` |
| 新增或修改装备 | 在插件后台处理内容；前端主题设置只改变显示配置 |

## 数据与展示

内容依赖 `equipments`、`groups` 和 `equipmentFinder`。分组地址使用资源名称而非显示标题。展示字段包括 `spec.displayName`、`cover`、`specification`、`description`、`url` 与 `groupName`。

封面使用 Halo thumbnail 的响应式尺寸；首屏首张图优先加载，其余图片延迟加载。缺少或加载失败的图片显示回退图标。分组可使用 `icon` 注解，配置方式见[图标与注解指南](../设置/图标与注解设置指南.md)。

## 空态、加载与导航

- 无装备数据时提示检查插件及内容；分组没有条目时显示「无记录」。
- HTML 下一页加载失败时保留已显示条目和可重试状态；可使用分页区域的重试操作继续加载。
- 当前续载仅检查 HTTP 状态与卡片选择器，登录重定向或缺少卡片的 HTML 可能结束列表；这些异常响应仍需专项复验。
- 页面销毁会中止在途请求，断开观察器和滚动监听；迟到响应不能追加到已离开的页面。
- 分组链接走主题 PJAX；外部装备链接保留浏览器原生行为。页面协议为 `data-app-root="equipments"`、`data-page-mode="browser-equipments"` 和 `data-window-variant="equipments"`。
