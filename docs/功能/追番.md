## 结论

`/bangumis` 现在是独立 App，不复用通用 browser 窗口。

- `pageMode = browser-bangumis`

## 数据契约

支持插件原生路由：

- `/bangumis`
- `/bangumis/page/{page}`

支持插件原生参数：

- `typeNum`: `1` 追番，`2` 追剧
- `status`: `0` 全部，`1` 想看，`2` 在看，`3` 已看
- `page`
- `size`

模板读取 `bangumis.items`、`bangumis.total`、`bangumis.page`、`bangumis.totalPages`、`bangumis.prevUrl`、`bangumis.nextUrl`。

## 交互

左侧边栏提供类型和状态筛选，全部走 PJAX 链接。
当前状态的计数使用路由已返回的 `bangumis.total`；其他状态先显示“—”，页面可交互后通过同源 `/bangumis` 路由独立补全。每项失败只影响对应计数，保留“—”；刷新或切换筛选可重试。成功计数短时缓存，避免反复筛选时重复请求。模板渲染不再为四个状态同步调用 `bangumiFinder.list()`。
主区域使用封面列表卡片，展示评分、集数、类型、地区、简介和播放/弹幕/追番/投币指标。
分页使用滚动加载模式：触底后 fetch 插件下一页 HTML，校验完整页面协议和请求身份，再追加新的列表卡片，不替换当前窗口。网络失败或残缺的 `200` 响应保留游标并显示手动重试；插件明确返回的有效空页才结束分页。
搜索只过滤已加载条目，不改变插件分页结果。

首页 `plugin-bangumis.recent` 小组件不在 Halo 渲染首页时同步查询六组 Finder。已摆放且未隐藏的实例在浏览器按配置请求插件页面，并读取该页面的惰性 JSON 模型；同组合请求去重并缓存，超时或上游失败时显示重试。这里的“已摆放且未隐藏”不等于进入像素级视口。当前本地站点未摆放该组件，真实保存布局及通知中心实例仍待验证；隔离宿主已用本地插件路由真实数据检查渲染。
